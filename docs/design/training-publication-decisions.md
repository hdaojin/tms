# 训练计划、排班与任务的状态决策表

计划、整份排班、单条任务分别发布。计划可见和任务可执行是两件事：选手只看到计划和排班均已发布且分配给本人的有效任务。结束日期用于显示完成，历史记录仍按下表处理。

| 动作 | 执行者与前提 | 结果、审批及拒绝条件 |
| --- | --- | --- |
| 保存计划定义 | 有计划管理权限；首次保存后周期固定 | 未发布且无有效排班内容、任务时可改日期和时段；发布后仅维护标题、目标、排班人员和审批人员等独立字段。参与人员走单独入口 |
| 发布计划 | 有计划管理权限，名单和计划配置符合要求 | 计划正式发布；排班及任务维持原状态 |
| 保存日级或时段排班 | 有排班权限，计划已发布 | 首次填写（逐日、逐时段分别标记）或未发布排班直接保存，过期亦然。清空不重置首次标志 |
| 调整已发布排班 | 有排班权限，且非首次 | 提交原因；未过期由受影响教练确认后终审，过期直接终审。有效超级管理员可直接保存并留痕 |
| 发布整份排班 | 有排班权限，计划已发布 | 日期与启用时段须完整；全日均休息或不安排可免值班。发布排班不发布任务 |
| 填写或修改任务 | 有对应任务权限的排班人员或获明确分配的负责教练；计划和排班均已发布 | 草稿直接保存，即使已过期。已发布且过期的非首次补改须填写原因并终审；超级管理员可直接保存，业务约束和记录保留 |
| Excel 导入草稿 | 已发布的空计划；导入者具备配置权限 | 预览后事务确认，重检计划与选手名单。可同时生成草稿排班与任务；仍按顺序发布 |
| 发布任务 | 有任务发布资格；上级发布且任务满足校验。统一发布仅超级管理员或具备任务修改权限的计划排班人员 | 固化选手分配；导入任务使用导入时快照。统一发布复核任务、排班和名单，任一失败整批回滚 |
| 撤回发布 | 仅超级管理员，顺序为任务 → 排班 → 计划 | 有执行事实的任务不能撤回。保留内容及历史分配；随后按草稿规则修改，重新发布不自动扩大首次分配 |
| 清空 | 按任务、排班的顺序分别处理；填写原因并预览确认 | 草稿任务软取消，排班内容重置但保留日期/时段与首次标记；执行与历史事实保留 |

待审变更批准前，原安排有效。服务端终审重检权限及待审版本，发现过期快照不覆盖新内容。这里的「过期」按业务时段判断；是否能保存、是否要求审批还取决于发布状态、是否首次填写及操作者。
