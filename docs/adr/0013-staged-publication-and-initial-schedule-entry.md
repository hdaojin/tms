# ADR 0013：逐层发布、首次排班与精简计划条目

- 状态：已接受
- 日期：2026-11-02
- 调整 ADR 0011、0012 中的任务填写时机、主要教练、排序及批量入口约定。

计划先发布，才能填写排班；全部日期值班和已启用时段完整后才可统一发布排班（全部已启用时段均休息或不安排的日期可免值班），之后才能新增、编辑、发布任务。未启用时段不参与完整性检查。技术领域、综合、其他均须指定负责教练。综合、其他、休息和不安排是领域下拉的固定选项，只有休息和不安排可省略教练。排班只按完整性显示待排班、已排班两种状态。

日级信息和时段分别持久化 has_been_filled。首次填写免调整原因并直接保存，包括过期日期。清空或撤回不重置该标志。未发布排班和草稿任务的后续修改也免原因、直接保存并审计，包括过期及撤回后。已发布排班的非首次修改和已发布任务的过期修改继续使用现有原因、确认与终审链。执行事实、撤销分配及取消操作的业务校验继续适用。

有效超级管理员直接保存排班和任务内容调整，包括已发布及过期内容，原因选填，免教练确认和审批。保存仍校验业务约束并记录操作者、时间及前后内容。待审申请按原有版本校验处理。撤回发布、取消任务和清空仍按各自规则执行。

主要教练从当前训练计划模型中删除：移除时段 primary_coach、任务教练 role 及专用约束，保留教练成员关系、任务、执行与原始审计快照。Excel列布局保持不变，新导出不再标主次，旧（主）标记只作为兼容文本读取。

0017使用已有内容和可靠的调整快照回填首次标志，不能用 revision 推测填写历史。不完整旧排班撤回排班层发布，保留计划发布状态和其他数据。迁移前备份；无待审申请、异常旧教练归属或受影响执行事实是当前升级前提，发现不满足即中止，不自动处置。反向迁移不能恢复已经删除的主次信息，完整恢复须使用升级前备份。

日视图的值班与备注合并至日期列；明细和Excel保留独立列。日期固定升序，时段顺序固定。按上海当天对过去日期着淡底纹，完整自然周已结束才默认折叠；用户手动偏好优先。

本版本暂停快速/批量排班、复制、批量任务、快捷调班及卡片菜单：按钮禁用，新入口与确认请求拒绝执行，隐藏无可用动作的批量栏和勾选列。单时段与单日日级信息继续通过抽屉编辑，不扩展其他业务。
