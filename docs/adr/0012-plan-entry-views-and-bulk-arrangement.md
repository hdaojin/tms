# ADR 0012：计划条目共用数据、批量编排与分层撤回

- 状态：已接受
- 日期：2026-11-02
- 补充 ADR 0011。

日视图和明细视图使用同一组 TrainingScheduleDay、TrainingScheduleSlot 和 TrainingTask。两视图均按31个匹配日期分页，仅支持日期升降序，明细保持同日四时段顺序。未启用时段保留展示框架。周折叠仅属于日视图的浏览器偏好，不改变分页或持久化业务数据。

每个排班时段最多一条有效任务，由数据库条件唯一约束保证。草稿与已发布任务均占用时段，取消任务保留历史。迁移优先保留有执行事实的任务，其次保留已发布任务，同等条件下保留最早创建的一条，其余标记为已取消并保留关联记录。

计划日期行可编辑全天任务。上午、下午和晚上的负责名单必须至少有一位共同教练。普通教练本人须在交集中，早读名单包含本人时可一并编辑。超级管理员可编辑这三个时段，早读包含任一共同教练时也可一并编辑。全体负责按发布时固化的名单判断。实际写入仍按时段校验。统一安排需确认覆盖已有任务，保留任务身份、发布状态和执行历史，并在同一事务内保存或提交调整申请。

前台不维护任务类型目录；“其他”为排班专用领域选项，复用 general 的程序语义，不创建技术领域或技能树。保留内部状态码与旧数据，单领域约束继续由现有写入边界执行。全部明确分配的负责教练在具备基础 Permission 时可维护时段任务，不从技术领域或角色名称推导授权。

复制限定同一计划，保留目标日期和作息，不复制任务、发布状态或执行事实。批量任务追加独立草稿。批量编排、复制和交换都预览固定目标、来源及前后差异；确认和终审校验来源、目标、任务及发布快照。默认跳过冲突，显式覆盖仍受技能兼容和执行事实保护；清空或设为不安排不得隐式取消任务。多对象变更整体应用或整体失败，已发布及过期变更沿用统一审批链。

计划、排班、任务独立撤回；上级撤回不改变下级发布标记。任何受影响任务存在执行、进度等事实时禁止撤回。保留历史分配，重发不得因当前全体成员变化而扩大名单。撤回后的未过期编辑按草稿保存，过期编辑继续终审；全部动作记录审计历史。预览不授予写入权限，确认时须重新授权并锁定相关记录。

桌面排班使用右侧宽抽屉，任务使用独立弹窗，窄屏抽屉全宽。保存仅提交当前条目及版本；无筛选时更新受影响行，筛选可能改变结果成员时重新获取结果区，保留日期页、筛选和折叠偏好。

删除资格以计划和排班的当前发布状态为准。超级管理员确认删除符合条件的草稿时，计划及排班发布与撤回记录改为保存被删除计划的标识快照，保留原记录的主键、操作者、时间和内容，并追加删除记录。迁移审计引用和删除计划在同一事务内完成。任务、审批及其他受保护历史继续约束删除。
