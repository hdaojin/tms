# ADR 0016：训练日志草稿与模型调用

- 状态：已接受
- 日期：2026-11-12

训练完成情况以选手的官方任务分配和排班日期为键。选手一次保存当天勾选，系统保存清单快照、修订与派生执行状态。首次填报后固定子任务清单。已有文字填报可供历史补交使用。教练按负责时段读取有权访问的填报，按任务汇总。模型只收到作者确认的素材，教练汇总移除结构化选手身份字段。模型地址和凭据沿用个人模型授权，后台领取任务时重新验证可用性与素材范围。

数据库保存作者草稿及生成任务。任务中断后标为失败，用户确认后可重新发起。候选正文由作者采用，正式日志由作者确认并由文档渲染器生成 PDF。提交通过既有训练日志存储入口执行唯一性检查和文件清理。训练日志从提交成功开始进入统计和归档。

选手有当日官方任务时即可生成，个人完成事实取自本人填报。教练日志的任务级技术摘录取自结构化任务资料，并随正式在线日志归档。选手生成时按同周期、同日期、已发布时段的负责名单和本人任务交集复核引用。选手确认页显示来源摘要，发送消息临时携带摘录，选手快照记录引用与版本指纹。缺少任务级摘录的历史教练日志仍可按原有权限查阅。

管理员按角色维护实际使用的写作提示词和主体建议篇幅，系统附加输出结构与事实约束。日志标题从周期名称、技能项目名称和任务所属计划的实施对象生成，同日多个实施对象按任务顺序去重。正式提交时冻结标题。

作者填写的参考网页在预览阶段由 TMS 读取，摘录随预览快照保存，确认后按预览版本发送。请求限定为公开地址的 HTTP/HTTPS 默认端口，直接连接已检查的地址并拒绝重定向。网页正文只作为技术参考。作者从扩展信息单独保存插图，取消发送预览只撤销待确认的生成任务。

作者可以在预览中确认随文本发送的插图，或者选择本次仅生成正文。图片通过统一 AI 服务以内联数据发送，所选模型须支持图片输入，生成任务记录经确认的图片标识。模型只可在教练过程记录或选手学习笔记中引用这些图片，每张至多一次。文档通过私有草稿资产解析引用，候选预览展示模型略过的图片。新版日志文档按素材快照中的版式版本渲染，历史归档沿用各自版式。
