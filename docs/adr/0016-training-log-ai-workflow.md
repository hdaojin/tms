# ADR 0016：训练日志草稿与模型调用

- 状态：已接受
- 日期：2026-11-12

训练完成情况以选手的官方任务分配和排班日期为键。选手一次保存当天勾选，系统保存清单快照、修订与派生执行状态。首次填报后固定子任务清单。已有文字填报可供历史补交使用。教练按负责时段读取有权访问的填报，按任务汇总。模型只收到作者确认的文本，教练汇总移除结构化选手身份字段。图片留在 TMS，用于日志插图。模型地址和凭据沿用个人模型授权，后台领取任务时重新验证可用性与素材范围。

数据库保存作者草稿及生成任务。任务中断后标为失败，用户确认后可重新发起。候选正文由作者采用，正式日志由作者确认并由文档渲染器生成 PDF。提交通过既有训练日志存储入口执行唯一性检查和文件清理。训练日志从提交成功开始进入统计和归档。
