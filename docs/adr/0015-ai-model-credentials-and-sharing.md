# ADR 0015：AI 模型密钥与共享边界

- 状态：已接受
- 日期：2026-11-11

API 接入方式由代码注册，决定 LiteLLM Provider Key、认证和传输行为。超级管理员可用已注册的接入方式新增具名提供商，创建后不能更换接入方式；同一个 Provider Key 可用于多个提供商。个人的「自定义（OpenAI 兼容）」入口继续保留。

TMS 按账号保存模型配置。API 密钥使用独立的部署密钥加密，应用页面只向所有者返回遮罩预览。即使具备 TMS 超级管理员权限，仍需满足所有者条件才能访问该配置的详情与测试入口。所有者共享的是指定模型的使用权，密钥和 API 地址仍归所有者管理。

模型所有者可配置 API 基址。公开目标默认使用 HTTPS 443；内网或其他端口需要管理员明确放行。调用时校验并直连经过检查的 IP，保留 TLS 服务名校验并拒绝重定向。更换提供商或地址需要重新输入密钥。账号获得模型管理权限后即可从 TMS 服务器发起测试请求。应用进程须具备解密能力，部署密钥由运维独立保管，数据库备份的恢复也依赖对应部署密钥。

超级管理员可编辑提供商的默认地址、启停状态和模型目录。每个提供商可将一个启用的模型选项设为默认。新建配置会保存用户确认的完整地址、模型 ID 和调用参数，后续默认值调整不覆盖这些值。停用提供商时暂停该提供商的个人和共享调用，保留已保存的记录。

模型目录按模型声明图片输入、JSON 输出等能力，并允许配置接入方式支持的思考和采样参数及其建议值。按提供商、模型 ID 和可信地址匹配，可信地址包括内置地址及管理员当前设置的默认地址；这不会放宽出站网络限制。建议值仅在新建时预填。编辑以保存值为准，空值使用接口默认值。TMS 对采样参数校验类型、范围和调用适配器支持情况。模型列表查询仅提供候选 ID。

所有者手动测试成功后可共享，包括使用自定义地址的模型。修改提供商、地址、模型 ID、调用参数或密钥会使验证失效并暂停共享。超级管理员可下架任何已共享的模型，解除下架后由所有者重新决定是否共享。默认模型是用户对当前可用配置的显式选择，失效时提示重新选择。系统只保留当前配置最近一次测试的结果，认证头排除在记录之外，回复以纯文本显示。

共享范围分为私有、定向共享和全体共享。原公共模型升级后沿用全体共享。定向共享取指定用户与指定角色实时成员的并集，接收者仍须是有效账号并具备 AI 模型查看和共享使用权限。名单仅所有者可查看和修改，停用共享、配置失效、下架或切换到全体共享时保留。保存定向共享时至少需要一项，若名单因账号或角色被删除而变空，定向共享范围也随之变空。模型列表、默认选择和实际调用使用同一受众规则。
