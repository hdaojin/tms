# ADR 0005：技能树采用版本化 Skill 层级

- 状态：已接受
- 日期：2026-08-20

## 背景

固定的“分类 / 主题 / 技能”节点类型增加了录入认知负担，也限制了技能结构继续细化。分类和主题一旦被其他业务引用，又会与长期稳定 Skill 的身份产生重叠。

## 决策

1. Skill 是跨技能树版本长期稳定、可具有不同粒度的能力单元，也可以直接作为父技能。
2. SkillTreeNode 只保存 Skill 在某个 SkillTreeVersion、TechnicalDomain 中的版本化位置、父子关系和顺序；所有实际节点都关联 Skill，层级深度不设业务上限。
3. 同一 Skill 在同一版本中只挂载一次；删除树位置不删除 Skill，调整结构也不改变 Evidence、TrainingTask 或评分关联。
4. 树关系只表达组织和细化，不自动决定可考核性，也不产生分数、掌握度或其他属性的汇总与继承。
5. Skill 和树位置不使用由数据库主键包装的面向用户编号；正式名称与别名承担人工识别职责。

## 后果

项目级技能库会同时包含不同粒度的 Skill，父 Skill 仍可被考点或训练任务直接引用。日常维护通过当前标准技能树进行；Skill 改名会反映到所有版本，版本结构变化不会改变长期业务身份。

本决策不包含技能树版本冻结、拖拽交互、父技能聚合算法或从旧版本自动克隆新版本。
