# ADR 0011：计划分层发布与历史补改审批

- 状态：已接受
- 日期：2026-11-01
- 替代 ADR 0010 中统一发布、保存任务即发布及过期永久锁定的约定。

现行计划编辑规则以发布为结构锁定节点。训练周期首次保存后固定，日期范围和每日时段仅可在未发布且无有效任务和排班内容时修改，历史任务所引用的日期和时段快照保留。计划详情直接发布已保存的内容。旧作息变更申请可查阅或驳回，不能继续批准生效。下文保留当时的决策背景。

计划、排班与任务各有独立发布边界。2026-11-01 后续调整：计划表单组合两栏和单栏，上午、下午必填，早读和晚上可不设；默认作息存在数据库，由超级管理员通过后台调整。计划所属周期和日期首次保存后固定；结束日期过后动态展示已完成，不因读取页面写状态或改变发布可见性，也不禁止后续补改。

计划和任务提供保存、发布按钮，发布在同一事务内先保存再发布。排班编辑亦可保存后发布；排班时已允许当前主要教练填写任务，任务草稿不产生选手分配。选手按单条任务看见内容，必须同时满足计划发布、排班发布、任务发布及本人有效分配；空缺或不可见的时段内容留空。普通任务首次发布时固定参与名单，导入任务保留创建计划时选手快照供发布使用。

时段结束时间只决定普通写入与审批路径，不再表示永久禁止修改。当前主要教练和有相应权限的排班人员修改未过期任务直接生效并审计；过期任务定义、技能或分配变更先生成申请。已发布排班变更、过期补改及已发布作息变更使用统一调整工作流。新作息调整只更新尚未结束的快照，已结束的时间不通过计划编辑纠正。

未过期排班调整按原负责教练、新负责教练、受影响值班教练去重并依次确认，申请人提交视为本人同意。全部同意后由计划指定且具备基础审批权限的人员或有效超级管理员终审；涉及教练兼任终审人时须单独完成终审。任一拒绝则结束申请。过期补改说明原因与实际执行情况后直接进入终审，避免重复确认已在线下执行的事实。既有权限审批人自批仍可在完成所需教练确认后执行。

申请保存原始版本与内容，终审再次校验权限、版本和对象范围，整体原子应用。批准前原内容继续有效。全日或部分时段交换保留任务与执行主键、进度、反馈和附件；执行事实不会因排班纠正自动重置或移动到别的选手。待审任务附件属于 training 的私有申请记录，批准后复制到正式任务；下载同时检查申请范围。

`training.0014` 从每个旧计划自身一致的时段快照提取时间，不用当前全局配置覆盖历史；不一致或缺失者保留空值，由管理员补齐。旧计划发布标记优先使用已有排班发布时间；只有旧状态表明已发布而没有时间的，沿用最后保存时间作为兼容标记，不声称可还原真实发布时间。旧待审申请缺少新确认链，保留原记录并标记驳回、说明升级原因，需按新流程重新申请。历史执行及文件不迁移、不删除。
