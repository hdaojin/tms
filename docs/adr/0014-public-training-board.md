# ADR 0014：训练大屏独立授权公开展示

- 状态：已接受
- 日期：2026-11-09

训练室通过固定网址 `/training/board/` 免登录查看当天的任务安排。任务发布面向训练流程，匿名展示由超级管理员在已发布的训练计划详情页单独授权，初始清单为空。计划撤回发布时同事务移除授权，重新发布后须手动加入。同一个大屏可汇总多份计划。

大屏和刷新响应使用同一公开查询，只展示上海当天已发布的计划、排班和任务，公开字段为计划名称、时段及其起止时间、技术领域、任务标题。选手分配、执行进度、正文、附件和详情链接仍由登录后的业务页面授权提供。取消上屏或撤回发布后，下一次刷新移除对应内容。刷新失败时清除已有任务，页面继续重试。
