# ADR 0014：训练大屏独立授权公开展示

- 状态：已接受
- 日期：2026-11-09

训练室通过固定网址 `/training/board/` 免登录查看当天的任务安排。任务发布面向训练流程，匿名展示由超级管理员在已发布的训练计划详情页单独授权，初始清单为空。计划撤回发布时同事务移除授权，重新发布后须手动加入。大屏每次展示一份计划，多份计划按稳定顺序轮播。

大屏和刷新响应使用同一公开查询，只展示上海当天已发布的计划、排班和任务。公开字段包括计划名称、时段及其起止时间、技术领域、任务标题、时段负责教练姓名、当天值班教练姓名，以及该计划当天的匿名统计。任务数量按已发布任务定义计数，每项任务仅归入一个领域，优先取任务主要领域，其次取时段主要领域，其余归入「其他」。

选手任务完成率按当天已发布任务的有效执行分配计算，排除已撤销和已取消的执行记录，仅将已完成状态计为完成。大屏展示汇总百分比和数量。选手姓名、账号、个人完成率、个人状态和进度、反馈、任务正文、附件和详情链接仍由登录后的业务页面授权提供。

页面每 60 秒请求一次新数据。取消上屏或撤回发布后，下一次刷新移除对应内容。刷新失败时清除已有计划内容，页面继续重试。
