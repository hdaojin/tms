# examcontent 试题结构化

## 功能概述

examcontent 用于维护事件模块下的试题和结构化试题要求。原始试题文件通过资料资产保存，结构化要求保存在试题要求中。

## 入口路径

- 顶部导航：竞赛
- 侧边栏：竞赛 -> 试题内容 -> 试题 / 新增试题 / 试题要求 / 新增试题要求
- 前台路径：`/examcontent/`

## 权限

- 登录用户可查看试题和试题要求。
- 创建、编辑和维护试题要求需要 `examcontent.maintain_examcontent` 权限包中的对应权限。

## 关键概念

- 试题：绑定事件模块的题目对象。
- 试题要求：从题目中抽取或人工维护的显性要求、隐含考点或约束条件。
- 考点证据：手工维护的试题要求可生成已通过考点证据。

## 常见任务

1. 创建试题并绑定事件模块和原始资料资产。
2. 为试题新增结构化要求。
3. 标注能力领域、要求类型、来源位置和难度估计。
4. 在 knowledge 中查看由试题要求生成的考点证据并完成技能映射。

## 注意事项

- 试题要求的能力领域必须属于试题事件模块对应的技能项目。
- 后续解析器或 AI 生成的内容应先进入审核流程。
