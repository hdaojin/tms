# TMS 用户手册

本目录存放 TMS 系统的用户操作手册，面向系统使用人员，优先说明入口、角色、任务流程、字段含义和结果确认方式。

## 使用说明

- 移动端小屏下，可点击页面左上角菜单按钮打开完整导航抽屉。
- 菜单入口会按当前账号权限自动过滤。
- 顶部导航显示“首页、竞赛、标准、训练、奖惩、关于”等主要入口；未登录时只显示可匿名访问的入口。
- 左侧导航显示当前区域内的功能入口，进入子页面时只高亮最具体的当前菜单。
- “关于”页面由 flatpages 提供，默认路径为 `/about/site/`，作者信息路径为 `/about/author/`。
- 主题默认跟随系统；也可通过右上角主题菜单切换为浅色、深色、企业、商务或夜间。
- 页面查看、创建、编辑、导入、审核和删除均按业务权限包控制；对象级页面还会限制为本人或业务范围内的数据。
