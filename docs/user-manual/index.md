# TMS 用户手册

本目录用于存放 TMS 系统的用户操作手册，当前已覆盖 accounts、assessments、behaviors、competitions、curriculum、meetings、notes、samba、traininglogs 等模块，后续再逐步扩展到 skills 等模块。

## 使用说明

- 本手册面向系统使用人员，不面向开发人员。
- 本手册优先说明“从哪里进入、谁可以用、如何完成任务、结果如何确认”。
- 业务模型和技术实现仅在必要时作为术语说明出现，不作为正文主线。
- 移动端小屏下，可点击页面左上角菜单按钮打开完整导航抽屉；入口会按当前账号权限自动过滤，并尽量与桌面侧边栏保持一致。

1. 功能概述

3. 入口路径
4. 关键概念
5. 常见任务
6. 字段说明
