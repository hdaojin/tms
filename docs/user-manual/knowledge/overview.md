# knowledge 考点知识库

## 功能概述

knowledge 统一保存考点证据和技能映射，用于说明某个技能点曾在哪些试题、评分点、评分标准或人工补充中出现，以及折算分值。

## 入口路径

- 顶部导航：标准
- 侧边栏：标准 -> 考点知识 -> 考点证据 / 新增考点证据 / 新增技能映射 / 未映射考点
- 前台路径：`/knowledge/`

## 权限

- 登录用户可查看考点证据、映射和覆盖统计。
- 创建、编辑、审核、映射和删除映射需要 `knowledge.maintain_knowledge` 权限包中的对应权限。

## 关键概念

- 考点证据：试题要求、评分点、评分标准条目、评分脚本检查项、CMP 回传项或人工补充考点。
- 技能映射：考点证据到标准技能点的关联。
- 未映射考点：已通过但没有任何已通过技能映射的考点证据。
- 覆盖统计：只计算已通过证据和已通过映射，分值按 `estimated_mark * mapping.weight` 折算。

## 常见任务

1. 新增人工考点证据；人工证据默认已通过。
2. 在考点详情页为证据新增技能映射；人工映射默认已通过。
3. 使用未映射工作台处理已通过但尚未映射的考点。
4. 审核通过或拒绝待审核证据；拒绝时必须填写备注。
5. 在标准技能树详情页查看覆盖统计。

## 注意事项

- 映射只能选择同一技能项目、当前技能树版本、启用状态的 `SKILL` 节点。
- `CATEGORY` 和 `TOPIC` 不能作为正式映射目标。
- 待审核或已拒绝映射不构成覆盖。
