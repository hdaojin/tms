# 我的 AI 模型

在「账户 → 用户中心 → 我的 AI 模型」管理已获授权的模型。管理员可分别为角色分配「AI 模型 | 管理自己的模型」和「AI 模型 | 使用共享模型」。

## 配置与测试

1. 点击「新增 AI 模型」，填写模型名称，搜索系统预设提供商或选择「自定义 API」。自定义接入使用 OpenAI 兼容协议，可以填写自己的提供商名称。预设提供商会填入默认 API 地址，可按需覆盖。公开地址默认使用 HTTPS 443，自托管或其他端口由管理员放行。凭据和消息会发送到所选地址。
2. 保存后打开模型详情，点击「发起测试」。系统会按保存的参数发送固定短句，显示最近一次的发送内容、模型回复、耗时或失败原因。测试可能产生少量费用，只有点击「发起测试」才会发送请求。
3. 长密钥的遮罩预览显示前三位和末四位，短密钥只显示遮罩。以前保存的预览会在替换密钥或下一次手动测试成功后更新。普通编辑时密钥留空即可保留，变更提供商或 API 地址时，要求认证的提供商需要重新输入密钥。

「模型 ID」可以直接输入，也可以打开「查看候选模型」选择推荐项。支持模型列表的提供商会显示「获取模型列表」，查询结果会加入原有候选列表。编辑时，如果提供商和地址相同，查询可沿用已保存的密钥。模型 ID 支持手输，包括目录尚未收录的新模型。

匹配目录预设时会显示可配置的高级请求参数。每项旁边有用途说明及管理员提供的建议值。新建时可修改或清空预填值，留空使用接口默认值。编辑以已保存的参数为准。

## 管理提供商

超级管理员可在「账户 → 系统管理 → AI 模型提供商」维护提供商默认地址和模型目录。打开模型选项的编辑页，在「高级请求参数预设」中勾选用户可配置的参数，按需填写建议值。预设匹配该提供商的内置地址或管理员配置的默认地址。勾选「设为默认模型」后，新建该提供商的配置时会预选该模型。已有配置继续使用已保存的地址、模型 ID 和参数。

在系统预设提供商的配置页，可以上传 PNG 或 WebP 来替换内置 Logo，文件大小上限为 1 MB。勾选「恢复内置 Logo」并保存后，选择器会重新显示内置 Logo。

## 共享与默认模型

- 新增模型默认为私有。测试成功后，在模型详情的「共享设置」中选择共享范围。可共享给所有有使用权限的用户，也可指定用户和角色。共享调用的费用由该 API 账号承担。
- 同一配置重新测试失败时，详情会显示最近失败的原因，并保留先前的验证资格。
- 定向共享至少选择一名用户或一个角色。支持按姓名、全拼或首字母搜索用户。指定用户和所选角色的当前成员都可在获得共享模型使用权限后使用该模型。
- 接收者可查看模型名称、提供商、模型 ID 和所有者，并可设为默认项。共享名单和连接配置由所有者管理。
- 切换为私有或全体共享时，系统保留已保存的定向名单。修改连接配置后需重新测试并保存共享设置。超级管理员可在「账户 → 系统管理 → 共享 AI 模型管理」下架模型，解除下架后由所有者重新开启共享。
- 在「训练日志 → AI 辅助编写」可以选用本人测试成功的模型或有权使用的共享模型。模型支持时可调整本次思考强度，并在发送前核对模型接收方与素材。默认项失效时需重新选择。
