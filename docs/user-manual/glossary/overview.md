# 专业词汇学习

## 功能概述

专业词汇学习用于按技能项目维护多个中英文专业词库，并提供词条浏览、自由输入答题、自适应复习和历史统计。词条可以是单词、短语、命令或路径。

## 适用角色与权限

- 所有登录用户：浏览已启用正式词条、开始学习、继续或停止本人会话、查看本人统计。
- 词条贡献者：获得“贡献专业词条”权限包后，可提交新词条，并修改本人待审核或已驳回的提案。
- 词库管理者：获得“管理专业词库”权限包后，可维护词库和正式词条、导入 Smartcat XLSX、审核提案、查看全部用户统计和私有导入留档。

## 入口路径

进入顶部“训练”，在左侧“专业词汇学习”中选择：

- “词条浏览”：搜索英文、中文或 Acronym。
- “开始学习”：选择词库、模式和题量。
- “我的统计”：查看会话历史及每个词条的累计表现。
- “词条提案”：贡献者查看和提交提案。
- “专业词库管理”：管理者维护词库、导入记录和全体统计。

## Smartcat XLSX 导入

1. 先创建专业词库并绑定技能项目。
2. 进入“导入记录”并选择“导入 Smartcat XLSX”。
3. 工作簿第 1 行必须包含 `Term` 和 `Translation (used for Smartcat - mandatory)`；`Acronym` 可选。
4. 系统会清理首尾空白、连续空白和不可见字符，并以清理后英文忽略大小写判重。
5. 内容完全相同的文件内重复行自动合并；内容不同的重复组必须选择保留行。
6. 库内重复默认跳过，可逐项选择覆盖或选择全部覆盖。待审核提案冲突不会被导入抢占。
7. 无效行会阻止整批确认，并显示工作表名和 Excel 行号。
8. 确认后原始 XLSX、SHA256、冲突决策及覆盖前后值保存在私有留档中。

导入不会停用或删除文件中未出现的旧词条。覆盖会保留词条 ID、启用状态和历史学习统计。

## 词条提案与审核

贡献者只能提交新词条，不能修改已经进入词库的正式词条。新提案默认待审核；管理者通过后才会生成正式词条。驳回必须填写原因，贡献者可以修改已驳回提案并重新提交。

## 学习模式与判题

- 英文答中文。
- 中文答英文。
- 均衡随机：两个方向数量尽量均衡，且不会连续超过两题同方向。

题量可选择 10、20、50 或不限量。每题只计一次，提交后显示对错和可接受答案；“不会”计为错误。Acronym 可作为英文答案，管理者维护的答案别名也可判对。系统不做模糊匹配，也不会忽略有意义的标点。

未按“停止”离开页面时，会话会保留；再次进入“开始学习”可选择继续或结束。停止时只统计已经提交的题目。

## 统计与限制

本人统计和管理统计都区分英文答中文、中文答英文，并提供总计、正确、错误、正确率和最近学习时间。管理者可按用户、技能项目、词库和日期筛选。

首版不提供离线学习、多词库混合会话、排行榜、通知和统计导出。
