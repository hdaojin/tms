# archives 资料资产

## 功能概述

archives 是统一资料资产登记层，用于查询、下载、上传和查看业务绑定对象。若具体业务页面已经内置上传流程，优先从业务页面发起；侧边栏“上传资料资产”更适合补录独立资料或历史资料。

## 入口路径

- 侧边栏：资料 -> 资料资产 -> 资料资产 / 上传资料资产
- 前台路径：`/archives/`

## 权限

- 登录用户可查看资料资产列表和详情。
- 上传、编辑、锁定或维护资料资产需要 `archives.maintain_archive` 权限包中的对应权限。

## 关键概念

- 资料类型：试题、评分表、评分标准、评分脚本、结果包、成绩表、训练日志、会议记录、学习资料等。
- 业务日期：资料归档和检索的业务时间。
- 绑定对象：资料资产可以绑定到事件模块、训练日志、试题、评分方案等业务对象。
- SHA256：用于识别同一文件内容。

## 常见任务

1. 查询资料资产列表并按类型、技能项目、日期定位资料。
2. 使用“上传资料资产”补录独立资料或历史资料。
3. 打开资产详情查看原始文件名、摘要、上传者、绑定对象。
4. 下载资料文件。

## 注意事项

- archives 不是脱离业务的公共上传中心。
- 私有资料只能通过系统页面下载，不应直接暴露文件目录。
