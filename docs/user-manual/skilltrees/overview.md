# skilltrees APP 总览

## 1. 功能定位

skilltrees APP 负责维护标准模块级、版本化的技能树。

技能树不是某一届竞赛的临时评分表，也不是自动从评分表生成的结果。它是训练分析使用的长期知识结构，用来归纳技能点、训练任务和能力层级。

## 2. 页面入口

入口位于“训练”区块中的“技能树”。

常见入口包括：

1. `/skilltrees/`：查看技能树列表。
2. `/skilltrees/create/`：新建技能树。
3. 技能树详情页：查看技能节点，并通过顶部单行快速表单新增节点，或在列表中编辑、停用节点。

新建、编辑和停用入口会按当前用户权限显示。

## 3. 关键概念

### 3.1 技能树

技能树归属于一个标准模块，并带有版本号。

同一个标准模块可以有多个技能树版本，但同一时间只允许一个版本标记为当前版本。

### 3.2 技能节点

技能节点是技能树中的层级节点，支持父子结构。

节点可以表示分类、专题、技能点或训练任务，并可配置代码、名称、说明、难度、排序和启用状态。

### 3.3 当前版本

当前版本表示默认用于新分析和新映射的技能树版本。启用新的当前版本后，旧版本会自动取消当前状态，但历史映射不会自动迁移。

### 3.4 详情页视图

单个技能树详情页提供两种查看方式：

1. 列表：默认视图，用于查看节点 ID、代码、名称、父节点、类型、说明、难度、排序、状态、创建时间、更新时间、考点覆盖等完整字段，并进行编辑、停用等维护操作。
2. 树形大纲：通过详情页的“树形大纲”入口或 `?view=tree` 参数打开，用于按父子层级只读浏览技能树结构和考点覆盖情况。

列表和树形大纲上方都会显示“快速新增节点”表单。表单字段和提交按钮横向排列在同一行，窄屏时可横向滚动，用于连续新增结构化节点。树形大纲不会提供拖拽排序、修改父节点或直接编辑节点的能力。需要修改已有节点时，应切回列表视图或进入节点编辑页。

技能点会显示直接关联的评分点数量、分值和明细。分类、专题和训练任务不会直接关联评分点，它们显示的是后代技能点的汇总覆盖情况。

## 4. 常见任务

### 4.1 新建技能树

1. 进入“训练 / 技能树 / 新建技能树”。
2. 选择标准模块。
3. 填写名称、版本和说明。
4. 根据需要标记为当前版本。

### 4.2 手工维护技能节点

1. 打开技能树详情页。
2. 在页面上方的单行“快速新增节点”表单中选择父节点、节点类型，填写代码和名称。
3. 提交后，当前列表或树形大纲会局部刷新，新节点会立即出现在当前视图中。
4. 如果需要填写说明等长文本，可在列表视图中进入节点编辑页补充。

### 4.3 停用节点

如果某个节点不再适合新训练使用，可以停用节点。停用不会删除历史记录，也不会破坏已有评分点映射。

## 5. 与 marking 的关系

marking 中的评分点可以人工映射到一个或多个技能点。

映射时可以设置：

1. 是否为主技能。
2. 权重。
3. 备注。

这样同一个评分点既能保留原始竞赛评分语义，也能进入长期训练分析口径。

技能树详情页会从这些映射关系反向展示考点覆盖，并提供跳转到来源评分方案的链接。映射关系的新增和删除仍在 marking 的评分方案页面完成。

## 6. 使用建议

1. 先按标准模块建立技能树，不要按某一届竞赛临时建树。
2. 评分表导入后，先整理评分点，再人工映射到技能点。
3. 当训练口径明显变化时，新建技能树版本，而不是直接覆盖旧版本。
4. 历史映射和历史分析应保留在当时使用的技能树版本上。
