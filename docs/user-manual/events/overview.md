# events 竞赛与考核事件

## 功能概述

events 用于维护赛事系列、赛事级别、事件、事件模块、参与人员和结果汇总。事件绑定技能项目；赛事系列和级别只是事件来源与层级，不复制技能项目。

## 入口路径

- 顶部导航：竞赛
- 侧边栏：竞赛 -> 赛事基础 -> 赛事系列 / 新增赛事系列 / 赛事级别 / 新增赛事级别
- 侧边栏：竞赛 -> 竞赛执行 -> 事件 / 新增事件 / 事件模块 / 新增事件模块 / 参与人员 / 新增参与人员
- 侧边栏：竞赛 -> 试题内容 -> 试题 / 新增试题 / 试题要求 / 新增试题要求
- 侧边栏：竞赛 -> 评分管理 -> 评分方案 / 导入评分表 / 新增参评对象 / 录入评分结果
- 前台路径：`/events/`

## 权限

- 登录用户可查看事件信息。
- 创建和维护事件、模块、参与人员、结果汇总需要 `events.maintain_event` 权限包中的对应权限。

## 关键概念

- 赛事系列：WorldSkills、国赛、省赛、校内选拔等来源。
- 赛事级别：世赛、国赛、省赛、训练考核等层级和统计权重。
- 事件：一次正式竞赛、选拔赛、训练考核、模拟赛或训练测试。
- 事件模块：某一次事件里的 A/B/C/D 等实际模块。
- 能力领域映射：一个事件模块可以映射多个长期能力领域，并可指定一个主领域。

## 常见任务

1. 维护赛事系列和赛事级别。
2. 创建事件并选择技能项目、系列、级别和日期。
3. 为事件创建实际模块，例如 A-Linux 或 B-Network。
4. 在事件模块详情页维护模块到能力领域的映射。
5. 维护事件参与人员和结果汇总。

## 注意事项

- 事件模块名称可以随年份变化，能力领域应保持长期稳定。
- 一个事件模块只能设置一个主能力领域，但可以附加多个辅助能力领域。
