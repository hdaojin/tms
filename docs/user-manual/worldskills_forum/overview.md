# 世赛论坛使用手册

## 功能概述

“世赛论坛”用于把世界技能论坛中持续演进的主题、帖子、中文翻译及附件统一归档到 TMS。中文翻译创建后立即发布，没有草稿、提交审核或审核状态。TMS 不会登录、抓取或自动下载世界技能论坛内容。

## 入口路径

- 顶部或首页导航：`世赛论坛`。
- 最新动态：`/worldskills-forum/`。
- 主题列表：`/worldskills-forum/topics/`。
- 翻译工作台：`/worldskills-forum/workbench/`，仅对具备翻译权限的用户显示。
- 专业词库：翻译工作台及发布页面中的“打开专业词库”。

## 角色与权限

### 阅读者

所有已登录用户均可查看最新动态、论坛主题、搜索结果、中文翻译、英文原文以及受控附件。阅读者不能创建或编辑内容。

### 翻译人员

管理员可在后台进入“认证和授权 → 组”，为翻译人员所属用户组勾选“翻译世赛论坛”业务权限包。该权限包自动授予：

- `worldskills_forum.add_forumtopic`
- `worldskills_forum.add_forumpost`
- `worldskills_forum.add_forumtranslation`

翻译人员可以创建主题、在任意已发布主题下发布翻译，并编辑自己创建的主题、帖子和译文。不能编辑其他翻译人员的内容，也不能删除已发布信息。

翻译人员可删除自己误建且尚无帖子的空主题。空主题在首条翻译发布前只对创建者和管理员可见。

### 管理员

管理员通过对应的 `change_*`、`delete_*` 权限管理全部主题、帖子和译文，并通过 Django 管理后台维护模块、分类、来源身份和标签。来源身份可以设置排序、启用状态、是否属于官方来源以及是否允许填写身份补充说明；停用身份不会出现在新建表单中，但历史帖子和编辑表单仍保留原值。帖子、译文和附件不能从管理后台分别新建，新内容必须走业务页面，以保证原子发布和上传校验。

## 关键概念

- 论坛主题：保存原始标题、中文标题、中文摘要、年份、模块、分类、标签、状态和来源链接。
- 论坛帖子：主题中的一条原帖，保存作者、身份、原发布时间、信息类型、重要程度和英文原文。
- 中文翻译：论坛帖子的一份正式译文；存在即代表已发布。
- 附件：属于论坛原帖，可为本地私有归档文件，也可只保存论坛来源网址。
- 阅读状态：按归档翻译发布时间记录用户最后查看主题的时间，而不是按论坛原发布时间判断。

## 浏览、搜索与筛选

最新动态按归档翻译发布时间倒序显示，可按关键字、年份、模块、分类、标签、信息类型和重要程度筛选。快捷入口包括：

- 重要信息：重要或紧急；
- 官方信息：世界技能组织官方、官方回复、官方通知或规则变更；
- 未读信息：翻译发布时间晚于当前用户最后查看时间的信息。

主题详情按论坛原发布时间展示连续时间线。中文默认显示，英文原文通过“查看英文原文”展开。后来补录的历史帖子在首次出现时会放在“你上次看到这里”之后，保证不会漏读；读完后的后续访问恢复完整论坛时间顺序。

## 创建主题与发布翻译

1. 在翻译工作台点击“创建新主题”。
2. 填写主题中文标题、论坛原始标题、论坛主题链接、年份、模块、分类、标签、状态、重要程度和中文摘要。标签可直接输入，多个标签使用逗号、分号或换行分隔；编辑时删除某个名称即可解除该主题与标签的关联。
3. 保存后继续录入首条帖子的作者、来源身份、论坛发布时间、信息类型、英文原文和中文翻译。论坛原始发布时间默认采用当前时间，可按原帖实际时间修改。
4. 可同时选择本地文件，或在“外部附件来源”中每行填写一个 HTTP/HTTPS URL。
5. 点击“直接发布”。帖子与中文翻译会在一个事务内创建。

若中途离开，空主题会出现在创建者工作台的“待发布首条翻译”区域，可继续录入或删除。

“世界技能组织官方”和“专家”等身份必须据实选择；“规则变更”仅用于已明确发生的规则变化。主题摘要描述当前结论或讨论状态，不应只是第一条帖子的译文。

## 编辑与删除

帖子编辑页同时修改英文原文信息和中文翻译，原翻译人及首次发布时间保持不变。附件通过独立“管理附件”页面维护。

翻译人员只能编辑自己的内容。管理员可编辑全部内容，并在具备删除权限时使用确认页删除已发布内容。删除主题会级联其帖子、中文翻译、阅读状态和附件。

## 图片和附件

本地归档文件位于 `PRIVATE_MEDIA_ROOT/worldskills_forum/`，不会由公开 `media/` 路径直接提供。登录用户通过受控地址查看或下载：

- JPG、JPEG、PNG、GIF、WebP 可在主题时间线内安全显示；
- PDF、Office、文本和压缩包强制下载；
- SVG、HTML、JavaScript 和可执行文件不允许本地上传；
- URL-only 外部图片只显示“论坛来源”链接，不会作为远程图片加载；
- 服务端不会根据任何来源 URL 自动请求、下载或同步文件。

每个帖子最多累计归档 10 个本地文件，单文件最大 50 MB，本地文件累计最大 100 MB。仅保存网址的记录不占本地文件数量和容量限额。删除附件或父帖子时，本地私有文件会同步清理。

## 重要限制

- 不提供世界技能论坛自动登录、抓取或同步。
- 不保存论坛账号、Cookie 或凭据。
- 不提供 AI 翻译、AI 摘要、审核流程或翻译版本历史。
- 不解析 PDF、Word、XLSX 等附件正文进行搜索。
- 不提供 PDF/Office 在线预览。
- 来源 URL 仅允许 HTTP/HTTPS，系统原样保存查询参数；填写含临时令牌的链接前应确认其内部可见范围。
