# meetings APP 总览

## 1. 适用对象

本手册适用于使用 meetings 页面查看会议记录、上传会议纪要和删除错误上传记录的用户。

典型角色包括：

- 超级管理员
- 拥有“上传会议记录”权限的管理人员
- 拥有“删除会议记录”权限的管理人员
- 登录后需要查阅会议资料的普通用户

## 2. 页面入口

系统入口位于侧边栏“会议 -> 会议记录”分组，包含“会议记录”和“上传会议记录”。当前前台路径为：

- `/meetings/`
- `/meetings/upload/`

常见进入顺序：

1. 进入“会议记录列表”查看已有记录。
2. 打开某条会议记录详情页在线预览 PDF。
3. 有权限时进入“上传会议记录”新增资料，或删除错误上传的数据。

## 3. 你能在这里做什么

meetings 主要负责会议记录文件的上传、查阅和维护。

主要功能包括：

1. 查看会议记录列表。
2. 打开会议详情页查看 PDF 预览。
3. 上传新的会议记录文件。
4. 删除误传或过期的会议记录。

## 4. 角色边界

### 4.1 登录用户

- 可以查看会议记录列表。
- 可以进入详情页查看会议文件。

### 4.2 上传权限人员

- 可以进入“上传会议记录”页面。
- 可以填写会议名称、会议日期并上传 PDF 文件。

### 4.3 删除权限人员

- 可以在列表页执行删除操作。
- 删除后原文件会随记录一并清理。

## 5. 关键页面

### 5.1 会议记录列表

作用：

- 查看会议日期、标题、上传者和上传时间。
- 在有权限时显示删除入口。

### 5.2 上传会议记录

作用：

- 上传 PDF 格式的会议记录。
- 要求填写会议实际发生日期，而不是上传日期。

### 5.3 会议详情

作用：

- 查看单条会议记录详情。
- 在线预览上传的 PDF 文件。

## 6. 使用提醒

1. 会议记录仅支持 PDF 格式。
2. 会议日期应填写会议实际发生日期，便于后续排序和检索。
3. 删除操作会同时移除数据库记录和对应上传文件，请谨慎执行。

## 7. 常见问题

### 7.1 为什么我能看列表但不能上传？

因为查看列表只要求登录，上传会议记录需要单独的权限。管理员通常会在后台通过“业务权限包”勾选“上传会议记录”来分配这项能力。

### 7.2 为什么上传失败提示文件格式不支持？

当前会议记录只接受 PDF 文件，请先将文件转换为 PDF 后再上传。

### 7.3 删除一条会议记录后，附件会保留吗？

不会。系统会在删除记录时同步清理对应的上传文件。
