# meetings APP 总览

## 1. 适用对象

本手册适用于使用 meetings 页面查看会议记录、上传会议纪要和删除错误上传记录的用户。

典型角色包括：

- 超级管理员
- 拥有“上传会议记录”权限的管理人员
- 拥有“删除会议记录”权限的管理人员
- 拥有“查看会议记录”权限的用户

## 2. 页面入口

系统入口位于侧边栏“会议 -> 会议记录”分组，包含“会议记录”和“上传会议记录”。当前前台路径为：

- `/meetings/`
- `/meetings/upload/`

常见进入顺序：

1. 进入“会议记录列表”查看已有记录。
2. 打开某条会议记录详情页在线预览 PDF。
3. 有权限时进入“上传会议记录”新增资料，或删除错误上传的数据。

## 3. 你能在这里做什么

meetings 主要负责会议记录文件的上传、查阅和维护。

主要功能包括：

1. 查看会议记录列表。
2. 打开会议详情页查看 PDF 预览。
3. 上传新的会议记录文件。
4. 删除误传或过期的会议记录。

## 4. 角色边界

### 4.1 拥有查看权限的有效登录用户

- 列表仅显示自己可见的会议，详情、PDF 预览和下载也遵循相同范围。
- “所有人”指所有具备会议查看权限的有效登录用户，不代表公开网页。指定某人或角色不会自动授予查看权限。

### 4.2 上传权限人员

- 可以进入“上传会议记录”页面。
- 可以填写会议名称、会议日期并上传 PDF 文件。
- 默认勾选“所有人”；取消后必须至少选择一个角色或指定人员。
- 多个角色和指定人员取并集，角色成员变化实时影响阅读资格。
- 指定人员按姓名或账号搜索，分批返回结果并支持多选；不展开全体用户。搜索结果仅含已启用且具备查看权限的人员。

### 4.3 删除权限人员

- 只能删除自己可见的记录，不能通过删除权限绕过可见范围。
- 删除事务提交后原文件会随记录一并清理。

### 4.4 可见人员维护

- 拥有“修改会议记录”权限且能查看记录的人，可以使用“设置可见人员”入口调整受众，不修改会议内容和文件。
- 超级管理员始终可见；上传者具备基础查看权限时始终可见自己的记录。其他管理员仍受可见范围约束。
- 普通阅读者只看到可见范围提示；具体角色和人员名单仅向有权维护受众的人展示。
- 原已选人员停用或失去查看权限时会标为“当前不可阅读”，可保留或移除。重新获得有效账号和查看权限前，该记录仍不可读。

## 5. 关键页面

### 5.1 会议记录列表

作用：

- 查看会议日期、标题、上传者和上传时间。
- 按会议名称、文件名、上传者姓名或账号搜索，也可按会议日期起止筛选；日期边界包含当天。
- 起止日期无效或起日晚于止日时显示错误和空结果，不会默默放宽范围。
- 支持排序和每页 20 条的分页，翻页和排序保留筛选条件。
- 在有权限时显示“设置可见人员”和删除入口；不提供批量操作。

### 5.2 上传会议记录

作用：

- 上传 PDF 格式的会议记录。
- 要求填写会议实际发生日期，而不是上传日期。
- 页面采用与日志提交页一致的通用卡片布局及文件上传组件。
- 切回“所有人”并保存会清空已存的角色和指定人员限制。保存前切换不会丢失当前输入，重置会恢复页面加载时的选择。

### 5.3 会议详情

作用：

- 查看文件名、大小、上传者、上传时间和会议日期。
- 在页面主体中在线预览通过文件类型校验的 PDF。
- 使用独立的“下载文件”按钮下载原文件。

## 6. 使用提醒

1. 会议记录仅支持 PDF 格式。
2. 会议日期应填写会议实际发生日期，便于后续排序和检索。
3. 删除操作会同时移除数据库记录和对应上传文件，请谨慎执行。

## 7. 常见问题

### 7.1 为什么我能看列表但不能上传？

查看会议记录需要“查看会议记录”权限；上传和删除分别使用对应权限包。会议详情、在线预览和下载都使用同一权限检查，不能通过公开媒体地址或直接猜测文件 URL 绕过。

### 7.2 为什么上传失败提示文件格式不支持？

当前会议记录只接受 PDF 文件，请先将文件转换为 PDF 后再上传。

### 7.3 删除一条会议记录后，附件会保留吗？

不会。系统会在删除事务成功提交后清理对应的上传文件；事务失败不删除原文件。

### 7.4 为什么被指定了，却仍看不到会议？

请确认账号已启用且具备“查看会议记录”权限。限定模式下还须命中所选角色或指定人员。角色退出、权限撤销或账号停用会使阅读资格失效。

历史会议默认保留“所有人可见”。所选角色或人员被删除后，限定会议不会自动变成“所有人可见”；请由上传者或超级管理员按权限维护受众。
