# assessments APP 总览

## 1. 适用对象

本手册适用于使用 assessments 页面查看考核、管理考核资料和查看评分归档汇总的用户。

典型角色包括：

- 超级管理员
- 拥有“查看所有人的考核成绩”权限的管理人员
- 被分配为考核模块负责人的教练
- 参加考核、只查看本人结果的学员

## 2. 页面入口

系统入口位于“竞赛”区块中的“考核列表”。当前前台路径为：

- `/assessments/`

常见进入顺序：

1. 进入“考核列表”。
2. 打开某次考核的详情页。
3. 在详情页按权限进入“导入评分表”“查看评分归档”或“上传资料”。

## 3. 你能在这里做什么

assessments 主要负责考核计划、考核模块、参考人员、资料上传与锁定。模块成绩由 marking 中的评分点级结果汇总，不再由 assessments 独立录入。

主要功能包括：

1. 查看进行中、即将开始和历史考核。
2. 查看某次考核下各模块的负责教练、满分、时长、资料状态和成绩状态。
3. 从考核模块进入 marking，导入评分表或查看评分归档。
4. 由负责教练上传试题、评分标准、评分表、评分脚本和试题附件。
5. 在资料或成绩确认完成后执行锁定。

## 4. 角色边界

### 4.1 超级管理员和授权管理人员

- 可以查看全部考核和全部人员成绩。
- 可以查看考核详情页的完整成绩汇总表。
- 可以执行成绩锁定与资料锁定。

### 4.2 负责教练

- 只能看到自己负责模块所属的考核。
- 可以进入所负责模块的评分表导入或评分归档页面。
- 可以上传和管理所负责模块的资料。
- 可以对自己负责模块执行锁定。

### 4.3 参加考核的学员

- 只能看到自己参与的考核。
- 历史考核页面只显示本人模块成绩、总分、排名分和排名；其中“排名分”只统计被标记为“计入排名分”的模块。
- 不能导入评分表，也不能管理资料。

## 5. 关键页面

### 5.1 考核列表

作用：

- 查看当前正在进行、即将开始和历史考核。
- 对管理角色显示可进入详情的管理入口。
- 对学员显示本人历史模块成绩和汇总结果。

### 5.2 考核详情

作用：

- 查看本次考核包含哪些模块。
- 查看本次考核所属训练周期，以及该周期绑定的标准模块版本。
- 查看每个模块的负责教练、满分、时长、资料上传情况和锁定状态。
- 对有权限的用户显示成绩表。

### 5.3 评分归档入口

作用：

- 从考核模块进入 marking，导入新版单模块评分表。
- 已有评分方案时，可查看评分点、J 分档、技能映射和结果导入入口。
- 已锁定模块不再显示新的评分表导入入口。

### 5.4 资料上传页

作用：

- 上传和管理试题、评分标准、评分表、评分脚本及试题附件。
- 资料锁定后页面转为只读。

## 6. 使用提醒

1. 模块成绩由 marking 的评分点级结果汇总，不在 assessments 中手工录入。
2. 每个考核必须归入训练周期。训练周期决定本次考核使用哪一个标准赛项、哪一版标准模块体系。
3. 考核模块只能选择该训练周期绑定的标准模块版本下的标准模块，不能跨版本或跨赛项选择模块。
4. 每个考核模块都可以单独配置是否“计入排名分”；关闭后该模块仍参与总分统计，但不参与排名分和名次计算。
5. 新建考核模块时，系统会默认继承该标准模块的“默认计入排名分”设置；如有特殊场景，可在具体考核模块里单独改写。
6. 在后台新建考核模块时，选择标准模块后，“计入排名分”会立即显示并自动跟随该标准模块默认值；一旦你手动勾选或取消，系统会保留你的改写，不再继续自动覆盖。
7. 一旦评分归档或资料被锁定，负责教练不能继续修改。
8. 试题附件会保存在独立的“试题附件”子目录下，便于与主文件区分。
9. 如需查看所有人成绩，必须具备对应权限，不能仅依赖登录状态。

## 7. 常见问题

### 7.1 为什么我能看到考核，但不能导入评分表？

因为只有该模块的负责教练，并且具备 marking 导入权限，或具备更高权限的管理人员，才能进入评分表导入页。

### 7.2 为什么上传资料按钮消失了？

通常是因为当前模块资料已经锁定，页面会自动切换为只读模式。

### 7.3 assessments 和 competitions 的边界是什么？

assessments 维护考核计划、模块、人员和资料；marking 维护评分表和评分点级结果；competitions 维护具体赛事、赛项和最终竞赛总成绩。

### 7.4 为什么考核模块里看不到某些标准模块？

考核所属训练周期已经绑定了标准模块版本。考核模块只能从该版本下选择标准模块，避免同一次考核混用不同版本的标准口径。
