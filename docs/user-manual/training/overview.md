# 训练管理

## 功能概述

训练管理覆盖训练周期、阶段、成员、训练计划、训练任务、选手执行、教练反馈和正式训练日志。

## 教练流程

1. 创建总周期或阶段周期，并为至少一个技术领域固定具体技能树版本。新建总周期默认选择各启用领域的当前版本；阶段周期只可使用父周期已有领域，但可选择不同版本。
2. 从周期详情进入“成员管理”，已有成员可按账号、姓名或学号搜索，按用户角色、周期身份和当前周期状态筛选；表格支持排序和分页。进入“添加成员”，从有效且尚未加入本周期的账号中勾选当前页用户，列表显示姓名、账号、角色和入读日期，默认按入读日期倒序。执行“添加周期成员”后填写统一的周期身份，预览固定名单和当前周期变化，再确认整批添加。具备成员修改权限的管理员可勾选“设为当前周期”，这会替换用户原来的当前周期；用户可以加入多个周期，但最多只有一个当前周期。已有成员不会自动设置当前周期。筛选、翻页或排序后需重新勾选；取消或完成操作后返回原列表条件。
3. 创建训练计划和具体任务，选择技术领域、主要技能、负责教练和明确的选手名单。
4. 发布后系统只为已选择选手创建执行记录，不自动分配全体选手。
5. 查看完成情况、问题和反思，填写教练反馈。
6. 依据 Skill 历史考查、训练投入和考核表现人工调整下一阶段任务；系统不会自动生成计划。

## 选手流程

1. 从“我的训练”查看本人被分配的任务。
2. 更新执行状态、实际用时、完成情况、问题、解决方法和个人总结。
3. 创建当天训练日志，可关联本人同周期且计划日期或实际执行日期覆盖当天的任务执行。
4. 查看教练反馈并继续训练。

## 训练日志提交统计

- 从训练导航进入“训练日志提交统计”，需要“查看训练日志统计”权限。选择训练周期、年份、月份和成员身份后查看；默认本月、全部身份，首次进入须选择周期。
- 页面显示每日已提交、未提交人员和个人提交天数。有日志查看权限时，可点击已提交人员姓名进入对应日志详情。
- 具有“查看全部训练日志”权限者及超级管理员可统计全部周期成员；其他人仅能选择本人加入的周期并查看本人统计。统计权限不额外授予日志详情或文件访问权限。
- 日期限定为所选月份与周期日期的交集，最多到上海时区今天。以周期现有成员为对照，包含停用账号，不受当前周期设置影响，也不能反映历史入训、离训变化。
- 按训练日期判断有无日志，历史补交会更新对应日期。未提交不代表缺交；当前不计算应交率、不判断迟交，待训练计划和任务启用后另行明确应交规则。

## 注意事项

- 日志列表的“作者”显示用户姓名，未填写姓名时显示用户名；列表展示训练日期、周期、作者、提交时间（精确到分钟）、附件文件名（无附件显示“未附文件”）及操作。
- 日志列表不展示训练内容及修改时间；提交时间取记录创建时间，历史补交通过醒目颜色和提示说明区分，历史记录不追溯标记。日志详情及 admin 后台列表和详情保留两组时间；后台详情中的时间只读。创建时间固定，每次成功保存都会刷新修改时间，包括只改关联任务或内容未变化的保存。后台支持按周期、训练日期筛选及按主题、摘要、作者和周期搜索。

- 从“提交当天训练日志”入口上传当天日志，训练日期固定为上海时区当天，不可修改，页面只显示管理员设置的当前周期，无需选择。历史日志可点击日期提示中的“补交入口”链接提交。未设置当前周期，或当前周期已完成、已归档时，无法提交当天日志，请联系管理员重新指定；系统不会自动切换。
- 所有新日志均须已加入所属周期，训练日期必须在周期日期范围内，且不得晚于上海时区当天；编辑日志也不能使用未来日期。导航中的“补交历史训练日志”入口可选择本人加入的进行中或已完成周期，不改变当前周期；筹备中或已归档周期不能补交。补交日期必须早于上海时区今天，不能选择今天或未来日期；补交沿用新增日志权限。
- 选手与教练均可上传日志，须已加入所选周期且填写真实姓名。文件名为“项目名称2026年03月02日选手日志-姓名.pdf”（教练对应“教练日志”），扩展名保持原样，按训练日期存入 `logs/<周期代码>/年/月/`。
- 同一周期、同一作者、同一天只能有一条日志；同周期内文件名也不能重复。重复时须先删除已有日志及文件，再重新上传。
- 训练主题与训练摘要均可留空。新增与历史补交均须上传“日志文件”，支持 doc、docx、pdf、txt、md，单文件不超过 20MB；页面提示与后台校验使用同一配置。已有无文件日志仍可编辑主题、摘要与关联执行，也可补充文件。详情统一使用文件预览页，PDF 支持在电脑和手机页面内逐页浏览，并保留下载入口。所有已有日志均不可修改所属周期；已有附件时只能编辑主题、摘要与关联执行，日期、文件不可修改，用户改名不会重命名旧文件。历史成员或日期异常不影响仅修改主题、摘要。
- 成员查看、添加、修改、删除分别需要对应的 Django 权限，周期内“教练”身份本身不授予管理权限。已有任务关联的成员不能改变身份或移除，已有日志的成员不能移除；管理页和后台均遵循这些限制。
- 删除需确认，会删除整条日志和附件，不删除任务执行本身。管理员可分别授予“删除本人日志”或“删除全部日志”权限包；查看、编辑权限不自动包含删除权限。
- 历史文件保留原名和存储位置，统一使用新详情页面。

- 一旦任一选手开始执行，任务日期、领域、技能和核心要求锁定；重大调整应取消旧任务并新建任务。
- 周期的领域版本快照只在“筹备中”且没有已开始执行时可调整；任务使用过的领域不能从周期中移除。
- 周期状态只允许按“筹备中 → 进行中 → 已完成 → 已归档”依次前进，不能回退。
- 训练任务只能选择当前周期已固定技能树版本的技术领域；既有任务绑定的停用领域仍会保留显示。
- 正式日志文件保存在训练业务私有存储中，只能经授权下载和导出。
