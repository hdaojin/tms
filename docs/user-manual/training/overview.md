# training 训练管理

## 功能概述

training 用于维护训练周期、训练日志、月度提交统计和训练日志 zip 导出。本轮只覆盖训练周期和日志归档，不包含完整训练计划或任务闭环。

## 入口路径

- 顶部导航：训练
- 侧边栏：训练 -> 训练管理 -> 训练周期 / 新增训练周期 / 训练日志 / 上传训练日志 / 提交统计
- 前台路径：`/training/`

## 权限

- “提交训练日志”允许查看、创建和修改本人日志。
- “查看全部训练日志”和“管理全部训练日志”分别扩大查看与修改范围。
- 训练统计和归档导出分别由“查看训练统计”和“导出训练日志”控制；导出只包含用户有权查看的日志。
- 训练周期的查看和维护使用独立权限包，不再由一个大而全的训练权限包同时授予。

## 关键概念

- 训练周期：一段训练管理时间范围，绑定技能项目。
- 训练日志：某个日期、上传者、训练周期、能力领域或训练主题的训练记录。
- 资料资产：训练日志上传文件会自动登记为资料资产。

## 常见任务

1. 创建训练周期并绑定技能项目。
2. 上传训练日志，选择训练周期、能力领域、训练日期和主题。
3. 在月度统计中查看人员按日提交情况。
4. 按月份，可选按训练周期筛选，导出训练日志 zip 包。

## 注意事项

- 能力领域必须属于训练周期对应的技能项目。
- 训练日志 zip 导出仍从“提交统计”页面按月份触发，不单独出现在侧边栏。
- zip 导出使用系统登记的资料资产，不依赖手工拷贝目录。
