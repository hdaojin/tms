# traininglogs APP 总览

## 1. 适用对象

本手册适用于使用 traininglogs 页面上传、查看和核对训练日志的用户。

典型角色包括：

- 选手
- 教练
- 超级管理员

## 2. 页面入口

系统入口位于“训练日志管理”区块，当前前台路径为：

- `/traininglogs/`
- `/traininglogs/coaches/`
- `/traininglogs/competitors/`
- `/traininglogs/upload/`
- `/traininglogs/stats/`

常见进入顺序：

1. 进入“我的训练日志”查看自己当月已提交的日志。
2. 选手进入“教练训练日志”查看教练提交的训练日志。
3. 教练进入“选手训练日志”查看选手提交的训练日志。
4. 需要补交时进入“上传训练日志”页面新增记录。

## 3. 你能在这里做什么

traininglogs 主要负责训练日志的上传、按月查看和跨角色查阅。

主要功能包括：

1. 查看自己按月提交的训练日志。
2. 选手查看教练的训练日志。
3. 教练查看选手的训练日志。
4. 打开单条日志详情页在线预览文件。
5. 在有权限时上传新的训练日志。
6. 按月份查看日志提交统计。

## 4. 角色边界

### 4.1 选手

- 可以查看“我的训练日志”。
- 可以查看“教练训练日志”。
- 不能查看其他选手的“选手训练日志”列表。

### 4.2 教练

- 可以查看“我的训练日志”。
- 可以查看“选手训练日志”。
- 不能查看其他教练的“教练训练日志”列表。

### 4.3 超级管理员

- 可以查看所有训练日志列表与详情。
- 可以使用各类管理入口排查提交情况。

### 4.4 拥有上传权限的用户

- 可以进入“上传训练日志”页面。
- 可以提交自己某一天对应的训练日志文件。

## 5. 关键页面

### 5.1 我的训练日志

作用：

- 按月份查看当前登录用户自己的训练日志。
- 默认显示当月数据。

### 5.2 教练训练日志

作用：

- 供选手查看教练提交的训练日志。
- 默认显示当月所有教练日志。

### 5.3 选手训练日志

作用：

- 供教练查看选手提交的训练日志。
- 默认显示当月所有选手日志。

### 5.4 上传训练日志

作用：

- 上传 Word 或 PDF 格式的训练日志。
- 日志日期应填写实际训练日期，而不是上传日期。

### 5.5 日志提交统计

作用：

- 按天查看选手已提交、未提交情况。
- 同时查看教练已提交情况，便于月度核对。

## 6. 使用提醒

1. 同一用户同一训练日期只能提交一条训练日志。
2. 训练日志日期应填写实际训练日期，便于按月统计和检索。
3. 选手与教练之间可以跨角色查看日志详情，但不能查看同组其他人的跨组列表。

## 7. 常见问题

### 7.1 为什么我看不到“教练训练日志”或“选手训练日志”菜单？

只有对应角色会显示相关入口：选手看到“教练训练日志”，教练看到“选手训练日志”。

### 7.2 为什么我能看自己的日志，但不能看同组其他人的列表？

traininglogs 只支持跨角色查看，不支持在该入口中浏览同组其他人的批量日志。

### 7.3 为什么上传时报“同一训练日期只能上传一条训练日志”？

系统要求同一用户每天只能保留一条日志。如需更正，请先删除原记录再重新上传。
