# competitions APP 前台业务录入手册

## 1. 适用对象

本手册适用于在 competitions 前台页面中补录业务数据的用户。

典型适用角色包括：

- 竞赛资料录入人员
- 成绩补录人员
- 被授权维护具体赛项业务信息的教师或工作人员

## 2. 前台可做什么

当前 competitions 前台支持的主要操作包括：

1. 查看竞赛列表
2. 查看赛事详情
3. 查看具体赛项详情
4. 新增代表队
5. 新增选手
6. 新增专家
7. 新增岗位人员
8. 录入竞赛总成绩

说明：

- 前台不负责维护赛事类型、标准赛项、标准模块、具体赛事和本届官方模块等主干信息。
- 如果某个具体赛项尚未由后台建立，前台无法直接补录该赛项的数据。

## 3. 页面入口

前台菜单入口位于“竞赛”区块，常用路径如下：

1. 进入“竞赛列表”查看全部赛事。
2. 在赛事详情页进入某个具体赛项详情。
3. 在具体赛项详情页进入新增代表队、选手、专家、岗位人员和录入总成绩页面。

## 4. 查看类页面

### 4.1 竞赛列表

作用：

- 查看系统中已经建立的全部具体赛事。
- 快速了解每个赛事下有多少具体赛项。

你可以在这里确认：

1. 赛事名称
2. 赛事类型与级别
3. 举办时间
4. 包含的赛项数量

### 4.2 赛事详情

作用：

- 查看某个具体赛事下包含哪些具体赛项。
- 查看赛事名称、赛事类型、赛事级别、举办地点、比赛时间和赛事描述等基础信息。
- 了解每个赛项的官方模块数、选手数、专家数和成绩数。

你可以在这里确认：

1. 当前赛事是否已经建好对应赛项
2. 当前赛事的比赛时间是否已经维护完整
3. 当前赛事是否补充了必要的背景描述或说明
4. 目标赛项是否已经具备后续录入条件

### 4.3 具体赛项详情

作用：

- 这是前台补录的核心页面。
- 页面会集中展示本届官方模块、代表队、选手、专家、岗位人员和最终竞赛总成绩。

你可以在这里完成两类事情：

1. 核对当前赛项的已有业务数据
2. 从页面按钮进入新增或录入流程

## 5. 常见任务

### 5.1 关联或新增代表队

适用场景：

- 某个具体赛项需要录入新的参赛代表队。

操作步骤：

1. 从具体赛项详情页点击“新增代表队”。
2. 如果系统里已经有符合当前赛事级别的代表队，先直接选择并关联到当前赛项。
3. 如果系统里没有需要的代表队，再填写新的代表队名称、代码和旗帜等信息。
4. 保存后返回具体赛项详情页。
字段说明：

- 已有代表队：只显示当前赛事级别允许、且尚未关联到本赛项的代表队。
- 新增代表队名称：仅在库中没有可复用代表队时填写。
- 新增代表队代码：全局唯一的代表队识别码。
- 代表队层级：从具体赛项详情页进入时，系统会按当前赛事级别自动确定，不需要手工选择。

结果确认：

- 具体赛项详情页的代表队表格中出现新记录。
- 即使暂时还没有录入选手或专家，已关联代表队也会先显示在赛项详情页。

### 5.2 新增选手

适用场景：

- 某个具体赛项需要补录参赛选手。

操作步骤：

1. 从具体赛项详情页点击“新增选手”。
2. 确认页面顶部显示的赛事和赛项名称正确。
3. 默认直接录入新的选手姓名、所属单位，以及可选的关联用户。
4. 如果该选手曾参加过往届或已在人员库中，再改为选择已有选手人员主档。
5. 选择代表队。
6. 填写性别等必要信息。
7. 保存。

字段说明：

- 具体赛项：从赛项详情页进入时由系统自动确定，本页面不再单独选择。
- 选手人员：默认直接新增本届选手；只有历史上已录入过该人员时，才需要选择已有人员主档。
- 代表队：系统只显示当前赛项已关联的代表队；如果缺少目标代表队，应先回到赛项详情页完成关联。

注意：

- 同一名选手在同一个具体赛项下不能重复新增；如果页面提示该选手已存在，请回到赛项详情页检查现有记录。

结果确认：

- 具体赛项详情页的选手表格中出现新记录。

### 5.3 新增专家

适用场景：

- 某个具体赛项需要补录专家或裁判。

操作步骤与选手类似，但专家记录同样只能选择当前赛项已关联的代表队。

结果确认：

- 具体赛项详情页的专家表格中出现新记录。

### 5.4 新增岗位人员

适用场景：

- 某个具体赛项需要录入场地经理、首席专家、翻译等岗位人员。

操作步骤：

1. 从具体赛项详情页点击“新增岗位人员”。
2. 选择已有岗位人员主档，或录入新的人员信息。
3. 填写岗位名称。
4. 按需要填写备注。
5. 保存。

结果确认：

- 具体赛项详情页的岗位人员表格中出现新记录。

### 5.5 录入竞赛总成绩

适用场景：

- 某个具体赛项需要补录选手的最终归档总成绩。

操作步骤：

1. 从具体赛项详情页点击“录入总成绩”。
2. 先确认当前具体赛项。
3. 选择尚未录入总成绩的选手。
4. 填写百分制成绩、700 分制成绩、排名和奖项。
5. 保存。

字段说明：

- 选手字段只会显示当前具体赛项下尚未录入最终总成绩的选手。
- 模块级成绩不在本页面录入，本页面只录最终归档总成绩。

结果确认：

- 具体赛项详情页的“最终竞赛总成绩”表格中出现新记录。

## 6. 前台完整示例流程

下面用一个完整示例说明前台录入人员如何围绕一个具体赛项完成补录。

### 6.1 示例场景

假设后台已经建立好“第 48 届世界技能大赛 / 网络系统管理”具体赛项，现在需要前台录入人员补录代表队、选手、专家、岗位人员和最终总成绩。

### 6.2 推荐操作顺序

1. 先进入竞赛列表，找到目标赛事。
2. 打开赛事详情页，进入目标具体赛项详情页。
3. 先检查该赛项页面是否已经显示官方模块和当前要求代表队层级。
4. 如缺代表队，先在赛项详情页关联已有代表队；如果库中没有，再新增代表队。
5. 再新增选手。
6. 再新增专家和岗位人员。
7. 比赛结束后录入最终竞赛总成绩。
8. 返回具体赛项详情页，逐项核对最终展示结果。

### 6.3 每一步要确认什么

进入赛项详情页时，先确认：

- 当前打开的是正确的赛事和具体赛项。
- 页面顶部显示的代表队层级要求是否符合业务预期。

新增代表队时，确认：

- 优先复用已有代表队，只在确实没有时再新增。
- 从赛项详情页新增时，系统会自动采用当前赛项要求的代表队层级。
- 保存后，代表队即使还没有选手或专家，也应先出现在赛项详情页的“代表队”区块。

新增选手时，确认：

- 默认直接新增本届选手，只有历史人员才复用已有主档。
- 代表队下拉框里出现的是当前赛项已经关联的代表队。
- 保存后选手出现在赛项详情页的“选手”区块。

新增专家时，确认：

- 专家人员是否优先复用了已有主档。
- 代表队是否正确。
- 保存后专家出现在“专家”区块。

新增岗位人员时，确认：

- 岗位名称是否准确，例如首席专家、场地经理、翻译等。
- 若同一人员在不同赛事再次参与，可直接复用已有人员主档。

录入总成绩时，确认：

- 选手下拉框只显示当前赛项且尚未录过总成绩的选手。
- 排名、奖项、百分制成绩、700 分制成绩是否录入完整。
- 保存后总成绩表格中出现新记录。

### 6.4 补录完成后的核对清单

完成一轮补录后，建议在赛项详情页依次核对：

1. 官方模块区块是否正常显示。
2. 代表队区块是否包含本次新增的代表队。
3. 选手区块是否包含本次新增的选手。
4. 专家区块是否包含本次新增的专家。
5. 岗位人员区块是否包含本次新增的岗位人员。
6. 最终竞赛总成绩区块是否包含本次新增的成绩记录。

## 7. 权限说明

### 7.1 查看权限

所有登录用户都可以查看：

1. 竞赛列表
2. 赛事详情
3. 具体赛项详情

### 7.2 录入权限

只有拥有对应新增权限时，用户才可以：

1. 在菜单中看到对应入口
2. 在具体赛项详情页看到对应按钮并打开录入页面
3. 成功提交数据

## 8. 常见问题

### 8.1 为什么我看不到“新增选手”或“录入竞赛总成绩”按钮？

因为当前账号没有对应的新增权限，或者你当前不在具体赛项详情页。

### 8.2 为什么代表队下拉框里没有我要选的代表队？

因为系统会按当前具体赛项对应的赛事级别自动过滤代表队。请先确认：

1. 该代表队是否已经建立
2. 该代表队层级是否与当前赛事级别匹配

### 8.3 为什么选手、专家、岗位人员有时可以直接复用？

因为系统使用了可复用的竞赛人员主档。若该人员已经录入过，再次使用时优先选择已有人员即可。

### 8.4 为什么总成绩页面选不到某些选手？

因为该页面默认只显示当前具体赛项下尚未录入最终总成绩的选手。

### 8.5 页面功能变了，但手册和实际页面不一致怎么办？

这说明手册还没有同步更新。遇到菜单入口、字段含义、页面布局、权限要求变化时，应同步修订对应 APP 的用户手册。
