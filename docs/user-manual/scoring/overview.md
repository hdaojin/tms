# 评分管理

## 功能概述

评分管理从 AssessmentModule 的评分表资料执行“解析 → 预览 → 确认”，生成评分方案、评分子项、评分点和评价分档。每个确认后的评分点自动生成已批准考点证据。

## 导入流程

1. 在竞赛与考核模块上传“评分表”类型资料。
2. 进入“导入评分表”，选择评分表资料和已启用解析器。
3. 核对模块、总分、评分子项、评分点和 J 分档预览。
4. 确认生成评分方案；若已有真实评分结果，系统禁止覆盖原方案。
5. 维护参评对象并录入或导入真实评分结果。

## 结果与 Skill

评分结果不直接写入 Skill。系统沿“评分结果 → 评分点 → 已批准 Evidence → 已批准映射 → Skill”按映射权重动态折算表现。

## 注意事项

- 当前默认解析器严格解析 CMP 单模块 `.xlsx` 评分表。
- 来源评分表必须属于目标 AssessmentModule。
- 导入确认可安全重复执行；已经确认的同一导入记录返回原评分方案。
