# notices APP 总览

## 1. 适用对象

本手册适用于需要查看通知公告、发布通知以及维护本人已发布通知的用户。

典型角色包括：

- 超级管理员
- 拥有“发布通知”权限的管理人员
- 登录后需要查看通知公告的普通用户

## 2. 页面入口

系统入口位于“通知公告管理”区块，当前前台路径为：

- /notices/
- /notices/create/

常见进入顺序：

1. 进入“通知公告列表”查看已发布通知。
2. 打开单条通知详情页查看正文与附件。
3. 有权限时进入“创建通知公告”页面发布新通知。

## 3. 你能在这里做什么

notices 主要负责通知公告的发布、查看与本人通知维护。

主要功能包括：

1. 查看自己可见的通知公告列表。
2. 打开通知详情页查看正文与附件。
3. 发布新的通知公告并上传多个附件。
4. 删除自己误发的通知公告。

## 4. 角色边界

### 4.1 登录用户

- 可以查看自己有权限看到的通知列表。
- 可以打开通知详情页查看正文和附件。

### 4.2 发布权限人员

- 可以看到“创建通知公告”入口。
- 可以填写标题、正文、目标范围并发布通知。
- 可以一次上传多个附件。

### 4.3 通知发布者

- 可以删除自己发布的通知。
- 不能删除其他人发布的通知。

## 5. 关键页面

### 5.1 通知公告列表

作用：

- 查看你当前可见的通知公告。
- 打开单条通知详情。
- 在有权限且满足条件时进入创建或删除流程。

### 5.2 创建通知公告

作用：

- 发布新的通知公告。
- 可按业务需要上传多个附件。
- 默认直接记录当前发布人。

### 5.3 通知详情

作用：

- 查看通知正文。
- 下载或查看附件。

## 6. 使用提醒

1. 没有“发布通知”权限时，系统不会显示“创建通知公告”入口。
2. 删除操作仅适用于你本人发布的通知。
3. 如果通知附带多个附件，请在发布前确认文件已全部选择完成。

## 7. 常见问题

### 7.1 为什么我能看通知列表，但不能发布通知？

因为查看通知列表只要求登录并满足可见范围，发布通知需要单独的权限。管理员通常会在后台通过“业务权限包”勾选“发布通知”来分配这项能力。

### 7.2 为什么我不能删除某条通知？

系统只允许通知发布者本人删除自己发布的通知；即使你能查看该通知，也不能删除其他人发布的内容。

### 7.3 发布通知时可以上传几个附件？

可以一次选择并上传多个附件。发布成功后，附件会一起绑定到这条通知上。
