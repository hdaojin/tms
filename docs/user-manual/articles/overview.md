# articles APP 总览

## 1. 模块定位

articles 当前被标记为低优先实验模块。

这意味着：

- 该模块暂时只保留基础文章浏览能力。
- 页面结构、展示方式和管理流程后续都可能调整。
- 当前不建议把它作为关键业务信息发布的唯一入口。

## 2. 适用对象

本模块仅适合内部试用、样式验证或低风险内容展示。

如果内容需要稳定发布、明确权限控制或长期维护，优先使用 notices、notes 或其他正式业务模块。

## 3. 入口路径

- `/articles/`：文章列表页
- `/articles/<slug>/`：文章详情页

## 4. 当前能力边界

已保留：

- 登录后浏览文章列表（列表仅展示已发布文章）
- 打开已发布文章详情

暂不承诺稳定的部分：

- 页面样式与交互结构
- 发布流与内容治理规则
- 与站点导航、权限体系的长期集成方式

## 5. 使用提醒

1. 如果页面提示“低优先实验模块”，属于预期行为，不是异常。
2. 实验模块中的内容和入口可能在后续版本中被调整、合并或移除。
3. 需要正式通知、长期沉淀资料或严格权限控制时，不建议继续扩展 articles。
