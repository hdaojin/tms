# articles APP 总览

## 1. 当前状态

articles 模块当前已停用。

这意味着：

- 前台不再加载 `/articles/` 入口。
- 后台不再注册 articles app。
- 代码、模型和迁移文件暂时保留，用于后续需要时恢复或迁移历史数据。
- 既有数据库表不会在本次停用中删除。

## 2. 适用对象

当前没有面向普通用户的可用入口。

如果需要发布正式通知、沉淀长期资料或进行有权限控制的内容管理，请优先使用 notices、notes 或其他正式业务模块。

## 3. 入口路径

- 当前无有效前台入口。
- 旧路径 `/articles/` 与 `/articles/<slug>/` 已从主路由移除。

## 4. 当前能力边界

已保留在代码仓库中：

- `articles/` app 源码
- articles 迁移文件
- 既有数据库表

当前不再提供：

- 前台文章列表与详情访问
- 后台 articles app 加载
- 面向用户的文章发布工作流

## 5. 使用提醒

1. 停用不是删除数据；如果未来需要恢复，应先评估现有数据和迁移状态。
2. 不建议在当前版本继续扩展 articles 功能。
3. 需要正式内容发布时，请改用 notices 或 notes。
