# 我的 AI 模型

在「账户 → 用户中心 → 我的 AI 模型」管理已获授权的模型。管理员可分别为角色分配「AI 模型 | 管理自己的模型」和「AI 模型 | 使用公共模型」。

## 配置与测试

1. 点击「新增 AI 模型」，选择 DeepSeek 并填写显示名称。API 地址下方会显示留空时使用的地址。可直接填写中转站或自部署服务的 HTTP/HTTPS 基址，并选择推荐模型或手动填写模型 ID。在「高级选项」中可调整思考模式和思考强度。凭据和消息会发送到所填地址。
2. 保存后打开模型详情，点击「发起测试」。系统会按保存的参数发送固定短句，显示最近一次的发送内容、模型回复、耗时或失败原因。测试可能产生少量费用，只有点击「发起测试」才会发送请求。
3. 长密钥的遮罩预览显示前三位和末四位，短密钥只显示遮罩。以前保存的预览会在替换密钥或下一次手动测试成功后更新。普通编辑时密钥留空即可保留，变更 API 地址需要重新输入密钥。

## 管理提供商

超级管理员可在「账户 → 系统管理 → AI 模型提供商」查看默认地址、默认模型和可选模型数量。进入提供商配置后可填写默认地址和思考参数，并维护可选模型的模型 ID 和显示名称。勾选「设为默认模型」后，用户新建该提供商的模型配置时会预选这一项。已有模型保留保存时的地址、模型 ID 和参数。

## 共享与默认模型

- 新增模型默认为私有。包括自定义地址在内的模型均可在测试成功后勾选「共享为公共模型」。共享调用的费用由该 API 账号承担。
- 公共模型使用者可查看模型名称、提供商、模型 ID 和所有者。首期可选择公共模型作为默认项，真实测试由所有者发起。
- 修改 API 地址、模型 ID、思考参数或密钥后需重新手动测试，再开启共享。所有者可取消共享。超级管理员可在「账户 → 系统管理 → 公共 AI 模型管理」下架模型，解除下架后由所有者重新开启共享。
- 在「训练日志 → AI 辅助编写」可以选用本人测试成功的模型或有权使用的公共模型。可调整本次思考强度，并在发送前核对模型接收方与素材。默认项失效时需重新选择。
