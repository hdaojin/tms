# 奖惩

从「奖惩 → 奖惩记录」查看事项、分档、积分和审核状态。按训练周期、学员、性质、日期或状态筛选。旧记录也在这里，周期显示为「未关联周期」，保留原积分、状态和附件。点击事项名称进入详情。

## 录入与审核

1. 在「奖惩记录」点击「录入奖惩」，选择训练周期和发生日期。系统加载当天生效的条例。
2. 选择学员和事项分档，填写数量与事实。预览会显示基准分 × 倍率 × 数量，以及本次每人的积分。固定分值档数量为 1。条例允许的零倍率档也可以登记。
3. 确认名单后可添加附件并提交。多人同次录入时，每人各有一条待审记录。录入人可编辑本人提交的待审记录，也可从驳回或作废记录复制重报。
4. 审核人按「待审核」筛选，进入详情后通过或填写原因驳回。已通过的周期记录可填写原因作废，积分随之撤回，再按需要补录。未关联周期的旧待审记录由超级管理员审核。

「积分汇总」只统计已通过的记录，按学员、训练周期逐行显示。周期记录分别显示竞赛奖励、日常管理和日常学习小计。未关联周期记录显示合计和奖惩次数。

## 班级条例与经办分工

在「班级条例」选择周期，查看可见版本及单独的计分附表。经办人可新建条例、复制已发布版本为草稿，或在空白周期载入精英班条例草稿。发布前核对正文、适用情形、单位与分值。

在草稿的计分附表先选共享事项，再为它添加分档。事项的基准分默认取自共享目录，可以按本版本的条例调整。分档可以选用通用程度和倍率，也可以自定义。例如基准分 +20、一等奖倍率 ×1.50，每次记 +30 分。发布后，条例版本中的名称、分档和计分参数固定。

超级管理员在「经办分工」选择周期，指定录入、审核、编写和发布人员。经办人同时需要对应的功能权限。

## 全局奖惩配置

明确取得全局配置权限的人员可以维护「奖惩配置」。在「奖惩分类」点击分类名称进入所属事项列表，再新增或编辑事项。在「程度与倍率」分别维护奖励和惩罚可用的档位、倍率、默认档与启用状态。共享配置供编写条例时选用，当前使用的具体标准可在已发布条例的计分附表查询。
