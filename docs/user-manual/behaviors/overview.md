# behaviors APP 总览

## 1. 适用对象

本手册适用于使用 behaviors 页面查看本人奖惩记录、查看奖惩汇总，或按权限录入奖惩记录的用户。

典型角色包括：

- 超级管理员
- 拥有“查看所有奖惩记录”权限的管理人员
- 拥有“录入奖惩记录”权限的教练或班务人员
- 只查看本人记录与汇总的学员

## 2. 页面入口

系统入口位于“学生奖惩管理”区块，当前前台路径为：

- `/behaviors/`
- `/behaviors/summary/`
- `/behaviors/create/`

常见进入顺序：

1. 进入“奖惩记录列表”查看本人或全部记录。
2. 进入“奖惩汇总”查看累计得分、奖励次数和惩罚次数。
3. 有录入权限时，进入“录入奖惩记录”填写事项、程度、日期和附件。

## 3. 你能在这里做什么

behaviors 主要负责学生奖惩记录的录入、审核后汇总展示，以及附件留痕。

主要功能包括：

1. 查看奖惩记录列表。
2. 查看奖惩汇总列表。
3. 录入奖惩事项、严重程度、发生日期和说明。
4. 上传奖惩附件作为佐证材料。

## 4. 角色边界

### 4.1 超级管理员和授权管理人员

- 可以查看全部学生的奖惩记录。
- 可以查看全部学生的奖惩汇总。
- 可以按后台权限执行录入或审核操作。

### 4.2 录入人员

- 可以进入“录入奖惩记录”页面新增记录。
- 如果没有“查看所有奖惩记录”权限，前台列表和汇总页只显示本人相关数据。

### 4.3 学员

- 登录后可以查看自己的奖惩记录列表。
- 登录后可以查看自己的奖惩汇总。
- 不能录入他人记录，也不能查看他人数据。

## 5. 关键页面

### 5.1 奖惩记录列表

作用：

- 查看奖惩事项、程度、发生日期、状态和当前分值。
- 按权限决定是查看全部，还是只查看本人记录。

### 5.2 奖惩汇总

作用：

- 查看累计总分、奖励次数和惩罚次数。
- 汇总仅统计已通过的记录。

### 5.3 录入奖惩记录

作用：

- 选择奖惩性质后联动事项选项。
- 根据事项性质联动严重程度选项和系数文案。
- 上传附件作为奖惩依据。

## 6. 使用提醒

1. 奖励类事项的默认分值必须为正数，惩罚类事项的默认分值必须为负数。
2. 前台汇总只统计已通过状态的记录，待审核或已驳回不会计入总分。
3. 没有“查看所有奖惩记录”权限时，列表和汇总页只显示当前登录用户本人数据。

## 7. 常见问题

### 7.1 为什么我只能看到自己的记录？

因为当前账号没有“查看所有奖惩记录”权限，系统会自动把列表和汇总限制为本人数据。

### 7.2 为什么录入页面里不同事项的程度名称不一样？

系统会根据事项属于“奖励”还是“惩罚”自动切换程度名称和系数说明，这是正常行为。

### 7.3 汇总分数什么时候会更新？

当奖惩记录审核通过后，系统会自动重算对应学生的汇总分数。
