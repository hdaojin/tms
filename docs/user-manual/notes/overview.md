# notes APP 总览

## 1. 适用对象

本手册适用于使用 notes 页面查看笔记仓库、阅读仓库内 Markdown 笔记，以及打开仓库内图片或附件的用户。

典型角色包括：

- 超级管理员
- 被授权访问指定笔记仓库的用户组成员
- 只可访问公开仓库的普通登录用户

## 2. 页面入口

系统入口位于侧边栏“资料 -> 教学笔记 -> 笔记仓库”，当前常见前台路径为：

- `/notes/`
- `/notes/<repo>/`
- `/notes/<repo>/<slug>/`
- `/notes/<repo>/<slug>/print/`

仓库内图片、附件等资源由系统内部路径提供，通常通过笔记正文中的链接自动打开。

## 3. 你能在这里做什么

notes 主要负责按仓库组织的 Markdown 笔记阅读与资料浏览。

每个笔记仓库由两个配置共同确定：

- “访问标识”用于页面 URL、访问权限和缓存，不能包含斜杠。
- “相对路径”指向 `media-private/notes/` 下的实际目录，可以配置多级子目录。后台可输入 `/` 或 `\`，保存后统一显示为 `/`。

相对路径对应的目录是该笔记仓库不可越过的内容边界。正文、图片、附件和相对链接都只能访问该目录及其子目录；未在后台登记的物理目录不能通过猜测 URL 直接访问。

主要功能包括：

1. 查看当前账号可见的笔记仓库列表。
2. 打开仓库内 README 或具体笔记页面。
3. 使用打印页查看适合打印的笔记版本。
4. 打开笔记正文中引用的图片或附件资源。

## 4. 角色边界

### 4.1 超级管理员

- 可以查看已注册的全部笔记仓库。
- 可以访问设置为不可见的仓库。
- 可以打开仓库内笔记正文、打印页和附件资源。

### 4.2 被授权用户组成员

- 可以访问所属用户组被授权的笔记仓库。
- 可以打开该仓库中的笔记正文、打印页和正文引用的附件资源。

### 4.3 普通登录用户

- 当仓库未限制用户组时，可以访问该仓库。
- 当仓库限制了可见用户组时，未授权用户不能访问仓库内容或仓库内附件。

## 5. 关键页面

### 5.1 笔记仓库列表

作用：

- 展示当前账号可见的笔记仓库。
- 超级管理员可额外看到不可见仓库、未注册仓库和缺失目录的统计信息。

### 5.2 笔记详情页

作用：

- 渲染 Markdown 正文。
- README 可使用 `<!-- TOC -->` 与 `<!-- /TOC -->` 包裹课程目录；旧格式 `<!-- TOC_START -->` 与 `<!-- TOC_END -->` 仍然兼容。
- 桌面端（宽度不小于 1024px）左侧显示 README 课程目录，右侧使用全站布局的独立侧栏显示本文大纲，正文不再为大纲预留内嵌列；左右侧栏都会固定在可视区域内，不随正文滚动，内容过长时可在各自侧栏内滚动。左右侧栏始终等宽，在 1024–1279px 时各为 18rem，在更宽屏幕上各为 20rem。侧栏标题居中，目录列表整体居中但文字保持左对齐和层级缩进。窄屏通过正文上方的折叠面板查看，桌面端不会重复显示顶部大纲。
- 左侧课程目录最多显示三级；更深层级不显示，指向笔记仓库根目录之外的本地目录项会被省略。
- 右侧本文大纲固定收集正文的二、三、四级标题，并按标题关系缩进；一级标题和五级及更深标题不在大纲中显示。
- 上一篇/下一篇按照左侧课程目录从上到下、由父项进入子项的顺序生成。
- 讲义可使用标准 `<details>` 与 `<summary>` 包裹参考答案等 Markdown 内容；默认收起，源文档带 `open` 时默认展开，打印时会完整显示折叠内容。折叠块不支持嵌套，结构残缺时页面会安全显示解析提示和原始内容。
- 使用 `mermaid` fenced code block 编写的图形会在浏览器中自动渲染；图表固定使用浅色主题和白色背景，不跟随系统或页面主题切换。图形按自身固有尺寸居中显示且不会被放大，超出正文宽度时提供横向滚动，不缩小文字。时序图参与者框使用较宽尺寸，框内文字居中并支持换行。图形采用适合中文的界面字体和严格安全模式，不执行任意 HTML 或点击回调。图形语法错误时会保留源码并显示中文错误提示，不影响同页其他内容。
- 展示面包屑信息。

### 5.3 打印页

作用：

- 以更适合打印的形式展示笔记正文与摘要字段。
- Mermaid 图形会先以浅色主题完成渲染再打开打印窗口，折叠内容会全部展开。

### 5.4 仓库内附件资源

作用：

- 为笔记正文中的图片、附件等相对路径资源提供受控访问。
- 附件访问权限与所属笔记仓库保持一致，不会绕过仓库权限单独放行。

## 6. 使用提醒

1. notes 采用“按仓库控制权限”的方式，不区分同一仓库内不同笔记的单独授权。
2. 如果仓库配置了可见用户组，笔记正文、打印页和正文中的附件资源都会一起受限。
3. 访问标识、仓库相对路径、笔记 slug 和附件路径都经过安全校验，非法路径不会被访问。

## 7. 常见问题

### 7.1 为什么我能登录系统，但打开某个笔记仓库仍然提示无权限？

因为该仓库可能限制了可见用户组。只有被加入对应用户组，或使用超级管理员账号，才能访问该仓库内容。

### 7.2 为什么笔记正文能打开，但图片或附件打不开？

现在笔记正文和仓库内附件使用同一套仓库权限控制。如果当前账号没有该仓库访问权，附件资源也会被拒绝访问。

### 7.3 仓库在后台设置为“不可见”后会发生什么？

普通用户和普通授权用户都不会再看到或访问该仓库；超级管理员仍可用于排查和维护。
