# event_countdown APP 总览

## 1. 适用对象

本手册适用于需要在训练室大屏、会议室屏幕、集训基地入口屏幕展示竞赛或活动倒计时的管理员与现场工作人员。

典型场景包括：

- 世界技能大赛、全国技能大赛、省赛、市赛、校赛倒计时。
- 集训阶段考核、选拔赛、开营仪式、赛前会议、总结会等活动倒计时。
- 需要公开投屏展示、但不需要登录 TMS 后台的展示屏。

## 2. 页面入口

公开展示页面：

- /countdown/
- /countdown/<访问标识>/

后台维护入口：

- /admin/event_countdown/countdownevent/

系统不会在前台菜单中新增入口。管理员通常在 Django Admin 中维护事件，再把展示地址提供给大屏设备或会议室电脑。

## 3. 你能在这里做什么

event_countdown 用于维护和展示通用倒计时事件。

主要功能包括：

1. 在后台新增多个倒计时事件。
2. 为每个事件配置名称、副标题、项目名称、项目英文名称、类型、地点和目标时间。
3. 选择倒计时大屏主题风格；当前提供“网络系统管理大屏”主题。
4. 自定义倒计时前缀，例如“距离开幕还有”“距离比赛开始还有”。
5. 自定义倒计时结束后的提示语，例如“活动已经开始”“比赛已经开始”。
6. 通过访问标识固定访问某个启用事件。

## 4. 角色边界

### 4.1 管理员

- 可以在 Django Admin 中新增、编辑、启用或停用倒计时事件。
- 可以设置显示排序，控制 /countdown/ 默认展示哪个事件。
- 可以为固定投屏页面配置唯一访问标识。

### 4.2 大屏查看人员

- 可以直接访问公开倒计时页面。
- 不需要登录账号。
- 只能查看已启用的倒计时事件。

## 5. 关键页面

### 5.1 默认倒计时大屏

路径：

- /countdown/

作用：

- 展示当前启用事件中排序最靠前的一个。
- 排序规则为“显示排序”优先，其次按“目标时间”排序。
- 如果没有任何启用事件，页面会显示“暂无启用倒计时事件”的提示。

### 5.2 指定事件倒计时大屏

路径示例：

- /countdown/worldskills-2026/

作用：

- 展示访问标识匹配且已启用的事件。
- 如果访问标识不存在，或事件未启用，页面返回 404。

### 5.3 后台事件维护

路径：

- /admin/event_countdown/countdownevent/

作用：

- 新增、编辑、停用倒计时事件。
- 管理事件文案、目标时间、访问标识、排序和主题风格。

## 6. 字段说明

- 事件名称：显示在大屏中央第二行主标题位置，通常用于“某项目备战倒计时”等具体主题。
- 访问标识：用于 /countdown/<访问标识>/ 固定访问某个事件；可为空，但填写时必须唯一。
- 副标题：显示在大屏中央第一行最大标题位置，通常用于“上海 2026 世界技能大赛”“全国技能大赛冲刺”等赛事或阶段标题。
- 事件类型：用于右上角徽章展示，例如“世界技能大赛”“全国技能大赛”。
- 项目名称：显示在页面左上角主项目名称位置；为空时使用当前主题的默认项目名称。
- 项目英文名称：可选字段，填写后显示在页面左上角项目名称上方；为空时不显示英文行，也不会使用硬编码英文标识。
- 目标时间：倒计时结束时间，请使用系统时区对应的准确时间。
- 地点：显示在页面右上角，也会与目标年份、事件类型组合为中央胶囊标签。
- 主题风格：当前提供网络系统管理大屏风格。系统保留主题扩展能力，后续新增主题后可在此字段选择。
- 说明文字：显示在主标题下方。
- 倒计时前缀：显示在倒计时数字上方；为空时显示“距离开始还有”。
- 结束提示语：目标时间已到或已过时显示；为空时显示“活动已经开始”。
- 启用：控制事件是否可公开展示。
- 显示排序：控制 /countdown/ 默认展示顺序，数字越小越靠前。

## 7. 常见任务

### 7.1 新增“第四届全国技能大赛”倒计时

1. 进入 /admin/event_countdown/countdownevent/。
2. 点击“增加倒计时事件”。
3. 填写事件名称、副标题、事件类型、项目名称、目标时间和地点；如需左上角英文标识，可填写项目英文名称。
4. 如需固定访问地址，填写访问标识，例如 national-skills-2026。
5. 确认“启用”已勾选。
6. 保存后访问 /countdown/ 或 /countdown/national-skills-2026/。

### 7.2 临时停用某个倒计时

1. 进入后台事件列表。
2. 打开对应事件。
3. 取消勾选“启用”。
4. 保存后，该事件不会再通过公开倒计时页面展示。

## 8. 使用提醒

1. 倒计时每秒在浏览器端刷新，不会每秒请求后端。
2. 修改事件目标时间或文案后，需要刷新大屏页面才能读取最新配置。
3. /countdown/ 只展示排序最靠前的启用事件；如需展示指定事件，请使用访问标识路径。
4. 如果固定访问标识页面返回 404，请检查事件是否存在、访问标识是否正确、事件是否已启用。
5. 倒计时大屏按浏览器当前窗口全屏铺满设计，适合直接在 Edge、Chrome 等现代浏览器中投屏展示。
6. 网络主题使用本地背景图，背景图本身不降低透明度；页面仅保留轻微边缘暗角和必要的内容可读性遮罩。
7. 网络主题底部关键词和图标来自主题配置，例如 Linux、Windows Server、Network、Security、Automation、Troubleshooting；后续新增主题时可在主题配置中扩展。
8. 页面包含少量本地 CSS 信号流动动画；当浏览器或系统开启“减少动态效果”时，动画会自动降级为静态显示。
9. 大屏主题使用本地静态资源，不依赖 Google Fonts、CDN 字体或外部脚本；如需新增字体或插件，应先下载到项目静态目录后再引用。
