# 考点证据

## 功能概述

考点证据表达评分点、试题、评分标准、脚本检查项、CMP 结果项或人工补充的可审核事实，并通过加权映射关联稳定 Skill。

## 工作流程

1. 已确认评分表中的评分点自动生成已批准证据。
2. 有模块维护权限的教练可手工创建并直接批准证据；其他创建者进入待审核状态。
3. 为证据选择一个或多个 Skill，填写权重、来源和理由。
4. 只有已批准证据和已批准映射进入历史考查与评分表现统计。

## 权重与修正

- 单条映射权重必须大于 0 且不超过 1。
- 同一证据的已批准映射权重合计不能超过 1。
- 后续修正映射会让历史统计和评分表现按当前关系动态重算，不会改写原始评分结果。
