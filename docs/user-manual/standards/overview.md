# 标准体系

## 功能概述

标准体系维护技能项目、技术领域、稳定技能、技能树版本和 WSOS。技能是长期本体，同一技能可挂载到多个技能树版本，历史考点、训练任务和评分表现不会因换版而重绑。

## 入口与角色

- 入口：顶部“标准”，前台路径 `/standards/`。
- 侧边栏“标准技能树”会优先进入默认技能项目；存在多个启用项目且没有默认项目时，需要先选择项目。
- 技术教练按负责的主要技术领域维护 Skill。
- 项目管理员可维护全部领域、技能、技能树和 WSOS。

## 常见任务

1. 创建技能项目后，在“技能项目管理”中建立技术领域，并配置领域负责教练。
   - 可将一个启用的技能项目设为“默认项目”。系统会在需要选择技能项目的新建表单中预先选中它，仍允许手动改选。
   - 项目详情显示当前技能树、当前 WSOS 和各技术领域；技术领域卡片会显示当前树节点数。
2. 从项目详情进入具体技术领域的当前标准技能树。每个领域使用独立链接展示，不会在一个页面中混合多棵树。
3. 在树中创建、复用、编辑和组织 Skill。技能项目和技术领域由当前树位置确定。
   - Skill 不使用面向用户的业务编号，正式名称和别名用于识别同一长期技能。
   - 输入名称时会提示同项目内名称、别名或描述相近的已有技能。
   - 正式名称或别名精确冲突时不能重复创建；确认是同一技能时，可将当前叫法登记为已有技能的别名。
   - 高度相似但业务边界确实不同时，确认后填写描述说明区别，再继续创建。
4. 在树形工作台中，按技术领域组织 Skill 的层次结构。
   - 使用技术领域标题或 Skill 行上的“+”直接在树内添加根技能、子技能，也可从“⋯”菜单添加同级技能；层级不设固定上限。
   - 输入名称时可复用技能库中的已有 Skill；高度相似但确属新技能时，使用完整表单补充描述、别名和其他长期属性。
   - “⋯”菜单还可查看或编辑长期 Skill，以及移动、调整同级顺序或从当前版本移除树位置。
   - 从技能树移除只会删除版本中的位置关系，不会删除长期 Skill 及其 Evidence、训练任务和评分关联。
   - “未纳入当前树”会列出本领域尚未挂载到当前版本的启用主要 Skill；选择挂载位置即可重新加入树。
5. 从“技能树版本”打开历史版本，再选择技术领域查看其历史结构。
6. 创建 WSOS 版本和章节，将 Skill 映射到一个或多个章节。
7. 在 Skill 详情查看历史考查、训练投入和真实评分折算表现，并按需人工创建后续训练任务。

## 注意事项

- A/B/C/D 评测模块不是技术领域。
- 训练完成不表示掌握度；详情页不保存全局“掌握度”字段。
- 停用 Skill 可阻止后续选择，但历史关联仍保留。
- 停用技术领域中的历史树结构仍会显示，但不能新增 Skill 或移入其他分支。
- 编辑 Skill 的名称或领域属于修改长期属性；名称会反映到所有版本，领域修改不能使既有树位置失效。
- 技能库不是独立工作台；停用 Skill 不会出现在“未纳入当前树”列表中，技能详情的规范归属始终指向主要技术领域。
- 停用 Skill 的名称和别名仍参与查重，需要时应重新启用原技能，而不是创建重复记录。
- 全系统最多设置一个默认技能项目；停用默认项目之前，需要先取消默认状态或将其他启用项目设为默认。
