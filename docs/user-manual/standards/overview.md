# 标准体系

## 功能概述

标准体系维护技能项目、技术领域、稳定技能、技能树版本和 WSOS。技能是长期本体，同一技能可挂载到多个技能树版本，历史考点、训练任务和评分表现不会因换版而重绑。

## 入口与角色

- 入口：顶部“标准”，前台路径 `/standards/`。
- 侧边栏“技能目录”会优先进入默认技能项目；存在多个启用项目且没有默认项目时，需要先选择项目。
- 技术教练按负责的主要技术领域维护 Skill。
- 项目管理员可维护全部领域、技能、技能树和 WSOS。

## 常见任务

1. 创建技能项目后，从该项目的“技能目录”建立技术领域，并配置领域负责教练。
   - 可将一个启用的技能项目设为“默认项目”。系统会在需要选择技能项目的新建表单中预先选中它，仍允许手动改选。
   - 技能目录首页显示项目下的技术领域，以及当前账号有权查看的主要技能和关联技能数量。
2. 进入具体技术领域，在“技能条目”区域搜索、筛选和分页浏览技能。
   - 默认只显示启用的主要技能；开启“包含关联技能”后，会同时显示主要归属在其他领域的关联技能。
   - 技术领域信息、负责成员和编辑操作按当前账号权限显示。
3. 从具体技术领域点击“新增技能”。技能项目和主要技术领域由当前页面确定，只需填写技能内容和可选关联领域。
   - 技能编号由系统自动显示为 `SK-000123`，无需人工命名。
   - 输入至少 2 个字符后，系统会提示同项目内名称、别名或描述相近的已有技能。
   - 正式名称或别名精确冲突时不能重复创建；确认是同一技能时，可将当前叫法登记为已有技能的别名。
   - 高度相似但业务边界确实不同时，确认后填写描述说明区别，再继续创建。
4. 创建技能树版本，用分类、主题和技能节点组织 Skill。
5. 创建 WSOS 版本和章节，将 Skill 映射到一个或多个章节。
6. 在 Skill 详情查看历史考查、训练投入和真实评分折算表现，并按需人工创建后续训练任务。

## 注意事项

- A/B/C/D 评测模块不是技术领域。
- 训练完成不表示掌握度；详情页不保存全局“掌握度”字段。
- 停用 Skill 可阻止后续选择，但历史关联仍保留。
- 技能条目页默认隐藏停用 Skill，可通过状态筛选查看；技能详情的规范归属始终指向主要技术领域。
- 停用 Skill 的名称和别名仍参与查重，需要时应重新启用原技能，而不是创建重复记录。
- 全系统最多设置一个默认技能项目；停用默认项目之前，需要先取消默认状态或将其他启用项目设为默认。
