# standards 标准体系

## 功能概述

standards 用于维护长期标准体系：技能项目、能力领域、标准技能树版本和技能节点。技能树按整个技能项目做版本，不按赛事级别或某一次比赛拆分。

## 入口路径

- 顶部导航：标准
- 侧边栏：标准 -> 标准体系 -> 技能项目 / 新增技能项目 / 能力领域 / 新增能力领域 / 标准技能树版本 / 新增标准技能树版本 / 技能节点 / 新增技能节点
- 前台路径：`/standards/`

## 权限

- 登录用户可查看标准体系。
- 维护技能项目、能力领域、技能树版本和技能节点需要 `standards.maintain_standard` 权限包中的对应权限。

## 关键概念

- 技能项目：长期本体，例如“网络系统管理”。
- 能力领域：长期能力分区，例如 Linux、Windows、Network、Automation、Troubleshooting。
- 标准技能树版本：覆盖一个技能项目下所有能力领域的完整版本，同一项目同一时间只有一个当前版本。
- 技能节点：分为 `CATEGORY / TOPIC / SKILL`，正式映射只能落到启用的 `SKILL`。

## 常见任务

1. 新建技能项目后，在项目下建立能力领域。
2. 为技能项目创建一个当前标准技能树版本。
3. 在技能树版本中按能力领域维护技能分类、能力主题和标准技能点。
4. 通过“技能节点”列表集中查看、筛选或新增技能节点。
5. 在技能树详情页查看节点数量、覆盖技能点、未覆盖技能点和折算分值。

## 注意事项

- 不要为世赛、国赛、省赛分别创建“网络系统管理”技能项目。
- A/B/C/D 是事件模块，不是标准技能树里的长期能力领域。
- 停用技能节点只影响后续映射选择，不物理删除历史节点。
