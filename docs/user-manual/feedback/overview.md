# 意见反馈

## 功能概述

意见反馈用于提交 TMS 使用中的 Bug、功能需求、意见建议和投诉，并在同一条反馈下持续回复和查看处理结果。

## 提交反馈

进入“反馈 → 意见反馈列表”，点击“提交反馈”。选择反馈类型，填写标题和详细描述后提交。投诉类型默认勾选“仅工作人员可见”，如确实需要公开，可以手动取消。

## 匿名与私密

- “匿名提交”会隐藏普通用户看到的提交人姓名；系统仍会保存提交人，具备相应权限的工作人员可以查看身份。
- “仅工作人员可见”表示只有提交人和具备私密反馈查看权限的工作人员可以查看反馈、回复和附件。

两项可以独立组合，例如公开匿名反馈或私密实名反馈。

## 添加附件和截图

正文和回复都可以添加附件。可以点击选择文件、拖拽文件，或复制截图后在当前反馈或回复表单内直接按 Ctrl+V / Cmd+V 粘贴，无需先点击附件区域。提交前可以删除待上传文件。

每次最多添加 10 个附件，单个文件不超过 20MB，单次附件总大小不超过 50MB。支持常见图片、办公文档、文本文件和 ZIP 压缩包。

图片会显示缩略图，点击缩略图可以查看大图；其他文件点击文件名下载。

## 回复和状态

打开反馈详情后，在“添加回复”区域补充信息。反馈状态包括：

- 待处理：反馈尚未开始处理。
- 处理中：工作人员正在处理。
- 已解决：工作人员认为问题已经解决。
- 已关闭：该反馈处理流程结束。

工作人员会在详情页填写“处理结果”。已解决或已关闭的反馈必须填写处理结果；详情页会显示处理人和处理时间。
