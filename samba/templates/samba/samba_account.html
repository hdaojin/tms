如何访问 Samba 共享文件夹？
  1. 打开文件资源管理器
  2. 在地址栏中输入 \\{{ server_host }}
  3. 按 Enter 回车
  4. 在弹出的登录窗口中输入你的 Samba 用户名和密码
  5. 点击确定即可访问共享文件夹
提示：可以右键点击共享文件夹选择"映射网络驱动器"，方便日后快速访问。

方法一：使用文件管理器

  1. 打开文件管理器（如 Nautilus、Dolphin 等）
  2. 按 Ctrl + L 打开地址栏
  3. 输入 smb://{{ server_host }}
  4. 按提示输入用户名和密码

方法二：使用命令行挂载

sudo mount -t cifs //{{ server_host }}/共享名 /mnt/samba -o username=你的用户名
  1. 打开访达（Finder）
  2. 点击菜单栏 前往 → 连接服务器（或按 ⌘ + K）
  3. 在服务器地址中输入 smb://{{ server_host }}
  4. 点击连接
  5. 选择"注册用户"，输入你的 Samba 用户名和密码
  6. 选择要挂载的共享文件夹
提示：勾选"在我的钥匙串中记住此密码"可以免去下次输入密码。
